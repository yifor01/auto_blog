TL;DR：一份聚焦 Claude Code、OpenAI Codex 等 coding agent 實務技巧的免費指南，從心態到具體工作流一次涵蓋。

「寫程式碼變便宜了」，當這句話成立，工程師真正該練的技能反而變了。Simon Willison 把他這一年來跟 coding agent 交手的心得，整理成一份持續更新的線上指南。

🤔 為什麼需要一份「怎麼跟 agent 合作」的指南

這份指南聚焦於 agentic engineering，也就是如何有效使用像 Claude Code、OpenAI Codex 這類具備自主執行能力的 coding agent，把它們用出最好的結果。Willison 表示更多背景可以參考他的專案介紹文章。

🧩 16 個章節，從心法到具體技巧

目前指南共有 16 章，涵蓋範圍相當廣：

- 心態與原則類：What is agentic engineering?、Writing code is cheap now、Hoard things you know how to do、AI should help us produce better code、Anti-patterns: things to avoid、How coding agents work
- 工作流程類：Using Git with coding agents、Subagents、Red/green TDD、First run the tests、Agentic manual testing、Linear walkthroughs、Interactive explanations
- 實例案例類：GIF optimization tool using WebAssembly and Gifsicle、Adding a new content type to my blog-to-newsletter tool、Prompts I use

從章節安排可以看出一個清楚的脈絡：先建立「寫程式碼本身變便宜」之後的心態轉變，例如要更珍惜「你知道怎麼做」這件事本身，而不只是產出的程式碼；接著談如何搭配 Git、subagent、TDD 等既有工程紀律來駕馭 agent；最後用兩個真實專案案例（GIF 最佳化工具、部落格轉電子報工具新增內容類型）與一份「我在用的 prompts」清單收尾，示範怎麼把前面的原則落地。
