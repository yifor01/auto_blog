📌 【rowboatlabs】Rowboat：讓你的 Email 與會議記錄變成私人知識圖譜的 AI 工作夥伴  

想像一下，你的收件箱和會議筆記能自己串連成知識圖譜，隨時幫你產出簡報或會議簡報。這不是科幻，而是剛上 GitHub Trending 的開源專案。  

🤔 **為什麼需要一個長期存在的私人知識圖譜？**  
在日常工作中，郵件、會議紀錄和零散的筆記常常被埋在不同的應用裡，難以快速檢索與關聯。當資訊被孤立時，產出報告、備忘會議或追蹤某個主題都會花費額外的時間與精力。一個能夠持續累積、私下保存且可隨時查詢的知識圖譜，正是解決這種資訊孤島的直接途徑。  

🧪 **Rowboat 的核心設計：連接本地資料、建立 Markdown 為基礎的知識圖譜、利用上下文執行任務**  
Rowboat 是一個可下載的桌面應用（支援 Mac、Windows、Linux），它會在你的電腦上：  
- 連接 Gmail、Google Calendar 與 Google Drive（需自行提供 Google API 金鑰）  
- 讀取會議筆記與電子郵件，將其中的實體（人、公司、主題）與關係抽取出來  
- 把這些資訊以純文字的 Markdown 檔案形式儲存，構成一個可編輯、可視化的長期知識圖譜  
- 基於圖譜的上下文，執行使用者指定的任務，例如產出簡報、生成會議備忘或產出語音筆記  

📌 **核心發現：Rowboat 能做什麼**  
根據專案說明，Rowboat 提供以下可直接使用的功能：  
- **產生簡報**：輸入「Build me a deck about our next quarter roadmap」→ 根據知識圖譜內容自動產出 PDF  
- **會議準備**：輸入「Prep me for my meeting with Alex」→ 提取過去決策、未解決問題與相關郵件線程，形成簡潔的文字簡報或語音備忘  
- **主題追蹤**：對指定的人、公司或主題設定追蹤，Rowboat 會在新進的郵件或會議紀錄中自動更新關聯  
- **知識圖譜視覺化與編輯**：圖譜僅是一組 Markdown 檔案，可使用任何文字編輯器或支援圖譜視覺化的工具直接查看、修改與擴充  
- **語音筆記自動更新**：錄製語音備忘後，系統會自動擷取重點並寫回知識圖譜（需 Deepgram API 金鑰）  
- **可選擇的聲音輸出與網頁搜尋**：分別透過 ElevenLabs 與 Exa API 金鑰啟用語音合成與深度網路研究功能  

💡 **深入分析：知識圖譜的私有性與可編輯性**  
Rowboat 最值得注意的設計點是「一切在本機運行」。所有郵件、會議紀錄與推導出的知識圖譜都只存在於使用者自己的電腦上，除非使用者自行上傳或分享，否則資料不會離開本地環境。這意味著：  
- 資料障礙較低，適合對資料隱私有較高要求的團隊或個人  
- 知識圖譜採用開放的 Markdown 格式，使用者可直接用編輯器修改、加入註解或匯入其他筆記系統，避免被特定應用鎖定  
- 因為圖譜是可編輯的文字檔，未來也能透過腳本或其他工具進行批量處理、備份或與其他知識庫結合
