📌 Simon Willison 七月筆記：開放權重聯名信、AI 自動化研究加速與開發者工具觀察

TL;DR：微軟主導 235 家公司力挺開放權重、Anthropic 警告蒸餾風險、1,324 位前沿員工呼籲放緩自動化研究，兼談 Coding Agent 實戰與 Claude Code 悄悄換上 Bun Rust 版。

隨著 GPT-5.6 Sol 與 Claude Fable 5 同期現身，政策戰場比模型發布更熱鬧：微軟牽頭 235 家公司聯名反對禁令、Anthropic 三天後發文畫紅線、頂尖實驗室 1,324 位員工聯合要求「刻意放緩前沿」——這一個月的產業動態，寫給工程師看最合適。

🤔 **開放權重聯名信：微軟主導、235 家簽署、直指「單點故障」風險**

7 月 24 日發布的《開放權重與美國 AI 領導力》由微軟推動，簽署者包含 NVIDIA（黃仁勳首推）、Amazon、Y Combinator、Linux Foundation，OpenAI 稍後跟進。核心論點有三：封閉模型並非天生安全（會被入侵、濫用、且外部無法偵測失效）；將先進能力集中在少數封閉模型會製造單點故障、削弱競爭；開放權重模型讓廣大研究者與開發者能檢視行為、發現漏洞、開發防護並持續改進。信中罕見公開支持蒸餾，主張政策制定者不應將合法模型開發技術與挪用混為一談。

🤔 **Anthropic 回應：不禁開放權重、但要打擊「工業級蒸餾」**

三天後 Anthropic 發布《我們對開放權重模型的立場》。CEO Dario Amodei 強調威權政府可能建構比美國更強模型、模型可能被濫用於網攻或生物攻擊，呼籲「打擊工業級蒸餾作業」，同時聲明從未主張禁止開放權重模型。雙方分歧落在：是否將蒸餾視為合法開發手段、以及風險門檻設在哪裡。

🤔 **Pacing the Frontier：1,324 位前沿員工呼籲「刻意放緩」**

7 月 28 日發布的《Pacing the Frontier》由 1,324 位前沿 AI 公司員工聯署，簽署者包括 OpenAI 首席科學家 Jakub Pachocki、Ilya Sutskever（Safe Superintelligence）、Dario Amodei、Jack Clark（Anthropic）等。核心訴求：美國政府應支持國際合作，發展技術與治理工具以「刻意控制自動化 AI 開發的前沿節奏」。背景是激烈競爭與自動化 AI 研究加速雙重壓力——Anthropic 80% 程式碼由 Claude Code 產出、OpenAI 讓 Sol 將端到端服務成本降 20%、Kimi K3 設計晶片服務自架構奈米模型，皆為自動化研發已落地的具體跡象。

🧩 **Coding Agent 改變逆向工程的 ROI 方程式**

Willison 觀察到越來越多開發者用 Coding Agent 逆向工程並自動化家用裝置。過去技術可行但 ROI 不划算：未文件化、不穩定的 API 可能隨時變動，維護成本高。Agent 讓「嘗試並失敗」的成本大幅下降，初始開發與未來維護（或丟棄重寫）的心理負擔同步降低，使得原本不划算的自動化專案變得值得一試。

🧩 **Claude Code 已在生產環境跑 Bun Rust 版**

Bun 作者 Jarred Sumner 指出 Claude Code v2.1.181（6 月 17 日釋出）起改用 Rust 移植版 Bun。Willison 實測發現版本號顯示 `Bun v1.4.0 (macOS arm64)`，而 GitHub 最新正式版仍為 1.3.14（5 月 12 日），證實已在數百萬裝置上運行預覽版。啟動指令列出 563 個檔案名稱，Rust 版現已釋出為 Canary 頻道（`bun upgrade --canary` 可裝）。Jarred 評價：「Boring is good.」

💡 **資料中心用水：買高爾夫球場轉公園**

針對超大規模廠商面臨的水資源壓力，Willison 提出半開玩笑的建議：買下幾家高階鄉村俱樂部，將高爾夫球場改為公園、資助前會員改玩觀鳥。試算：Google 2025 年用水 109 億加侖（日均 3,000 萬加侖），Coachella Valley 120 個球場各耗 ~800 acre-feet/年（日均 ~75 萬加侖），買下 40 個（1/3）理論上可抵銷。這反映 AI 基礎設施資源外部性正被具體量化。

🎯 **實務啟示**

1. **開放權重政策走向直接影響模型獲取**：若美國限制開放權重，工程師將失去可自行部署、檢視、微調的模型選項；聯名信與 Anthropic 立場的博弈，將決定未來 1-2 年可用模型池的寬窄。
2. **自動化研發已改變成本結構**：Anthropic 80% 代碼由 AI 產出、OpenAI 服務成本降 20%，意味著「寫代碼」邊際成本趨近零。團隊應重新評估建構 vs 購買、自研 vs 微調的決策邏輯。
3. **工具鏈悄悄升級是常態**：Claude Code 換上 Bun Rust 版且無重大事故，說明生產級 Rust 執行環境已經過大規模驗證。關注工具鏈版本變更，有時比關注模型版本更能預判開發體驗變化。
4. **逆向工程自動化門檻已低**：若團隊有「一直想自動化但不划算」的舊裝置/內部系統，現在是用 Coding Agent 做 PoC 的最佳時機。
