📌 【Anthropic】Claude 11 天完成費馬大定理的完整形式化證明

TL;DR：Anthropic 用多個 Claude agent 平行協作，把費馬大定理翻譯成 Lean 可逐行驗證的形式化證明，耗時 11 天。

人類與費馬大定理糾纏了三個半世紀，Andrew Wiles 在 1994 年才補完證明缺口。而把這份證明翻譯成電腦能逐行檢查、沒有任何「這裡顯然成立」的形式化版本，帝國理工學院團隊原本規劃要花上多年時間。Anthropic 宣布，Claude 完成了這件事，只用了 11 天。

🤔 從「證明成立」到「電腦逐行認可」

費馬大定理指的是：對任意整數 n>2，不存在正整數 a、b、c 使 aⁿ+bⁿ=cⁿ 成立。這個命題陳述簡單，卻困擾數學界超過 350 年，直到 1993 年 Wiles 首次公開宣布證明，隨後審查發現缺口，他又與 Richard Taylor 花約一年時間補完，1994 年才真正完成。

但普通數學論文是寫給人看的，許多步驟人腦可以直接判斷「顯然成立」；Lean 這類證明助手系統則不接受這種跳步，它會逐一檢查每個推導是否合法地從既有公理與定理推出。這也是為什麼把一個大型現代數學證明「形式化」，工程量往往極為驚人。2024 年，帝國理工學院 Kevin Buzzard 等人才正式啟動一項多年的社群專案，準備用 Lean 完成費馬大定理形式化，光是第一階段的技術藍圖就寫了 86 頁。Anthropic 這次要驗證的，正是 Claude 能把這項工程推進到什麼程度。

🧩 多個 agent 同時攻不同定理，再拼回整個證明體系

主導這次專案的 Anthropic 研究員 Tianyi Peng，是清華姚班畢業、MIT 博士，目前也是哥倫比亞大學助理教授，長期研究強化學習、AI agent 與形式化工具。專案中，不同 agent 被同時拉起來平行工作：有的負責補齊數學定義，有的專攻中間引理，有的沿著既有成果往更高層定理推進，還有 agent 負責把各部分重新拼裝回完整的證明體系。

最終產出約 1300 萬行 Lean 程式碼、超過 3 萬個中間定理，實際用於最終證明的約 29500 個，整體規模超過 Lean 核心數學庫 Mathlib 本身的 5 倍。Anthropic 表示，完整證明只依賴 Lean 的三個標準公理，且已透過程式比對確認，Claude 最終證明的定理陳述與 Mathlib 裡收錄的費馬大定理完全一致。換句話說，判定是否成立的不是模型自己的宣稱，而是 Lean 這個「裁判」。

⚠️ 中途曾經失序，靠專案管理平臺救回來

專案並非一路順利。Anthropic 透露，早期多 agent 協作很快就撞上規模擴大後常見的問題：agent 逐漸跟不上整個專案的狀態，彼此難以有效協作，這些早期失敗嘗試留下的程式碼，最終只佔成品非模板程式碼的約 7%。

真正的轉折點，是團隊換上一套名為「Prove2Me」的協作平臺，由 Tianyi Peng 與哥倫比亞大學合作者專門為數學形式化打造。Prove2Me 把整個證明拆成一張由定理節點組成的有向無環圖（DAG），讓 agent 能從圖中判斷哪個定理已完成、哪個還缺前置條件、下一步該攻哪個節點；同時將定理陳述與證明分開管理、加速 Lean 編譯，並為每個定理保留自然語言描述，方便不同 agent 搜尋與重複使用既有成果。Anthropic 最終使用的方案是 Prove2Me 搭配基於 Claude Code 的 multi-agent harness，整個專案消耗約 60 億個輸出 token，內部使用的通用研究模型能力大致相當於 Claude Fable 5.1。

📊 人類只給高層提示，其餘由 Claude 自主完成

素材特別強調，人類在過程中提供的數學指導相當有限，Tianyi Peng 多半只偶爾給出高層次提示，例如某個方向優先順序較高、或某個定理該儘快推進，其餘大量的定義、中間證明、任務拆分與拼裝主要由 Claude 自行完成。負責審閱結果的 Kevin Buzzard 將其評價為一次「非凡的自動形式化成果」。

這個案例的意義不只在於費馬大定理又被驗證一次，而是說明像這樣規模龐大、依賴複雜度極高的現代數學成果，也開始具備被 AI 自動搬進形式化系統的可能性。如果你的工作也涉及需要大量平行協作、彼此依賴關係複雜的長流程任務，Prove2Me 這種把工作拆成 DAG、讓多個 agent 依賴圖判斷優先順序的做法，是值得參考的多 agent 專案管理框架方向。
