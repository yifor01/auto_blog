TL;DR：Anthropic 第五代 Opus 模型 Claude Opus 5 登陸 AWS，強化編碼、知識工作與長任務處理。

隨著 AI 代理（Agent）技術日益成熟，如何讓模型在處理長時程任務時保持穩定，成為企業進入生產環境的關鍵。Anthropic 此次推出的 Claude Opus 5，不僅是其第五代模型，更在處理複雜工作流方面取得了顯著進步。

🧩 **第五代 Opus 模型：針對生產環境工作流的最佳化**

Claude Opus 5 是 Anthropic 目前能力最強的 Opus 模型。根據官方描述，它在多項實際生產環境的任務中都有顯著提升，包含：
- 代理編碼（Agentic coding）：具備理解與導航程式碼庫的能力，能寫出具備生產品質的程式碼。
- 知識工作（Knowledge work）：對長檔案具備更深層的推理能力，並提升複雜分析的準確度。
- 視覺理解（Visual understanding）。
- 長時程任務（Long-running tasks）：能驅動可靠的代理進行長達數小時甚至 overnight（隔夜）的工作，具備避開障礙、錯誤恢復並達成目標的能力。

根據 Anthropic 宣稱，Claude Opus 5 在多個領域能達到 Claude Fable 5 的頂尖智慧水準，同時維持 Opus 等級的定價。

☁️ **整合 AWS：兼顧企業級安全與開發體驗**

透過 Amazon Bedrock 與 Claude Platform on AWS，工程師可以在現有的 AWS 環境中直接部署模型，並享有以下優勢：

- **預設零資料保留 (Zero Data Retention, ZDR)**：在 Amazon Bedrock 上使用時，預設提供 ZDR 服務，確保企業資料治理與安全性，無需擔心資料被保留。
- **下一代推論引擎**：利用 Bedrock 的推論技術，在維持區域資料駐留（Regional data residency）與企業級安全性的同時，實現零維運介入的推論擴展。
- **統一的開發體驗**：透過 Claude Platform on AWS，使用者可以在 AWS Console 中獲得與 Anthropic 原生平臺一致的 API、功能與控制台體驗，並與 AWS 帳單與身份驗證系統整合。
