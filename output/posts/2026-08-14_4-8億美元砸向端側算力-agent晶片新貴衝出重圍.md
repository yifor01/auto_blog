📌 融資逾4.8億美元，端側 Agent 晶片新創 Acrab 首顆晶片進入量產

TL;DR：新加坡新創 Acrab 拿下1.3億美元 B 輪融資，端側 AI 晶片 GΞLIX 1 開始量產，瞄準 Agent 時代的終端運算需求。

當雲端 GPU 戰場已經被巨頭卡滿位置，一家成立不到三年的新創，卻選擇從端側運算切入，短時間內完成晶片量產並拿下逾4.8億美元累計融資。這家公司就是總部位於新加坡的 Acrab。

🤔 **雲端擠滿了，運算需求開始往終端移動**

過去大模型時代的基礎設施競賽，幾乎都圍繞資料中心展開：模型愈大，需要的 GPU、頻寬與資料中心複雜度就愈高，資金與供應鏈門檻也隨之推高，微軟、Google、Meta、亞馬遜持續加碼，NVIDIA 站在這波擴張最核心的位置。相對地，過去端側 AI 承擔的多半是拍照、降噪、語音辨識這類固定功能，一顆 NPU 就足以應付，真正複雜的大模型推論仍留在雲端。

但隨著模型量化、壓縮與推論最佳化持續推進，加上 PC、汽車、機器人本身的記憶體、頻寬與運算能力提升，過去只能送上雲端處理的任務，開始有條件留在本地執行。Agent 的興起進一步放大這個需求：個人檔案、長期記憶、日程與裝置狀態本身就產生在終端，若每次讀取檔案、呼叫工具都要往返雲端，不僅延遲累積、按 token 計費的成本壓力也隨之升高。文章指出，這不代表端側會取代雲端，更可能的分工是：最複雜的推論留在資料中心，高頻、隱私敏感、需要低延遲與長期維持狀態的任務逐步移往終端。AMD 的 Agent Computer 概念，以及高通、NVIDIA 把更完整本地 AI 能力放進 PC 與邊緣運算平臺，都被視為同一方向的佈局。

🧩 **不只比 TOPS，還要比異構協同**

Acrab 成立於 2024 年，選擇切入的正是這塊還在成長的端側 Agent 運算需求，並依託團隊過去在大型伺服器晶片與系統軟體上的經驗，切入技術門檻更高的高階端側 AI 伺服器市場。

Acrab CEO Ken Phua 曾在 Arm UK 負責亞太應用工程並參與全球 IP 策略制定，之後擔任 Arm China 聯席 CEO。他的判斷是，AI 進入異構運算階段後，執行效率不只取決於 NPU，還取決於 CPU 與 NPU 能否順暢協同。因此 Acrab 最新推出的 AI 晶片 GΞLIX 1，除了主打峰值 700TOPS 運算能力外，也把統一記憶體、CPU 與 NPU 協同、Prefill（輸入處理）與 Agent 編排一併放進產品設計。公司名稱 Acrab 取自 Agentic、Compute、Reasoning、Action、Brain 字首，也來自天蠍座 β 星這個多恆星系統，寓意不同運算單元協同運作。

📊 **自測數據：Prefill 速度號稱快 7 倍**

Acrab 公佈了一組長上下文測試：在執行 Gemma 26B A4B 模型、4萬 token 上下文快取、1萬 token 輸入的條件下，GΞLIX 1 平臺的 Prefill 速度達到 1,416 token/s，號稱比業界領先的端側 AI 運算平臺快 7 倍。文章特別提醒，這組數據來自公司自測，實際表現仍會受模型載入、軟體排程與具體任務影響，還需要第三方進一步驗證。

在量產進度上，GΞLIX 晶片於 2025 年 11 月完成流片，隨後進入上電與系統驗證，據公司表示上電後 6 小時內通過 12 項關鍵驗證，24 小時內成功啟動 Linux 與 Android 系統。今年 7 月，GΞLIX 1 與搭載它的個人 AI 裝置 Agent Box 正式發布，目前第一代運算平臺已開始客戶匯入並推進規模化生產。最新一輪 1.3億美元 B 輪融資由 Vertex Growth 等機構參與，完成後 Acrab 累計融資已超過4.8億美元。

💡 **Agent Box：不只是一臺本地大模型電腦**

基於 GΞLIX 1，Acrab 打造了定位為 Personal AI Center 的桌面裝置 Agent Box，可在本地執行千億參數級模型，並整合長期記憶、多模態互動、工具呼叫與 Agent 編排。發布會上展示的情境是使用者提出想為孩子製作太空主題禮物，Agent 提供創意、協助選方案並呼叫工具推進製作,難點在於能否把一句自然語言拆解成連續動作，並讓任務狀態在模型與工具間持續傳遞。Acrab 的軟體平臺涵蓋本地大模型、最佳化後的 Runtime、開發工具與 Agent 編排，Agent Box 既是完整產品，也扮演參考系統的角色，用意是驗證完整 Agent 任務能否在本地執行，再把這套能力複製到 AI PC、AI NAS、汽車、工業裝置與機器人等不同終端。

⚠️ **從技術驗證走到商業化驗證**

文章提到，微軟 Azure 研究團隊近期發布的《Architectural Implications of Agentic AI Workflows》觀察到，Agent 任務會不斷在模型推論、工具呼叫與任務編排之間切換，反覆跨越 CPU 與 GPU 邊界，運算需求也不再像傳統推論那樣穩定，而是出現明顯的等待、恢復與短時峰值，這正呼應 Acrab 押注「終端需要一套新運算底座」而非單純更快 NPU 的邏輯。不過目前 GΞLIX 1 仍處於客戶匯入與量產驗證的早期階段，實際會進入哪些量產裝置、首批客戶何時出現，以及能否形成持續出貨,都還有待觀察。

🎯 **實務啟示**

對關注端側部署的工程師來說，Acrab 的案例值得留意的是它把「異構協同」而非單一 TOPS 數字當作產品核心指標，這與 Agent 工作負載在 CPU/GPU 間頻繁切換、需求呈現尖峰波動的特性相呼應。若團隊正在評估 Agent 應用的本地部署方案，統一記憶體架構與 Prefill 效能，可能比單看峰值算力更能反映實際使用體驗，但目前公開的效能數據仍以廠商自測為主,採用前建議留意後續第三方驗證結果。
