📌 【OpenAI 官方發布】GPT-Live-1 上線，語音 API 邁向全雙工對話

TL;DR：OpenAI 在 API 推出 GPT-Live-1，主打全雙工語音對話、更強的指令遵循與電話整合。

跟語音助理對話時最惱人的瞬間，往往不是它聽錯了什麼，而是你話講到一半，它卻還在自顧自地念稿，或是搶著打斷你。這種「輪流講話」的不自然感，正是 OpenAI 這次想在 API 層級解決的問題。

🤔 全雙工語音，才像真人對話

根據 OpenAI 官方部落格，GPT-Live-1 的核心賣點是為 API 帶來「natural, full-duplex voice conversations」，也就是雙方可以同時聽、同時說，不必等對方講完才能插話，讓語音互動更貼近真實對話的節奏。

🧩 三個重點：指令遵循、客製語音、電話支援

素材中提到 GPT-Live-1 的三項強化：更強的指令遵循能力（stronger instruction following）、可自訂的語音（custom voices），以及電話系統整合（telephony support）。這意味著開發者不只是把文字轉成語音，而是可以在通話情境中，讓模型更精準地照著設定的角色與規則行事。

🎯 實務啟示

對正在打造語音客服、語音助理或電話機器人的工程團隊來說，「全雙工＋電話支援」這個組合值得關注，因為它把過去需要額外拼接電話系統（telephony stack）與語音辨識/合成管線的工作，收斂進同一個 API 之中。至於延遲、成本與實際自然度如何，仍需等更多技術文件與實測資料出爐後再評估。
