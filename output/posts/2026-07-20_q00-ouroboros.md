TL;DR：ouroboros 是本地優先的 Agent OS，把 AI 編碼轉成可重播、受控的工作合約。

你還在對 Claude Code、Codex 反覆貼提示詞碰運氣嗎？ouroboros 主張：停止 prompting，開始 specifying——把模糊想法變成可驗證、可運作的程式碼庫，而且過程要能重播、能觀測、受政策約束。

🤔 **即興提示的痛點，與規格優先的取代方案**

README 指出，現有的 agent 工作往往是非確定性的（non-deterministic），依賴臨場的 ad-hoc prompting。ouroboros 定位為「Agent OS for AI coding」，是一個本地優先（local-first）的執行層（runtime layer），要把這種不確定的 agent 工作，轉換成可重播（replayable）、可觀測（observable）、受邊界策略繫結（policy-bound）的執行合約（execution contract）。

🧩 **核心工作流：訪談 → 結晶 → 執行 → 評估 → 演化**

專案用結構化的 specification-first 工作流取代隨手提示，流程拆解為五個階段：
- interview（訪談）：把模糊點子釐清
- crystallize（結晶）：形成明確規格
- execute（執行）：跑 agent 實作
- evaluate（評估）：驗證產出
- evolve（演化）：持續迭代

它聲稱可橫跨 Claude Code、Codex CLI、OpenCode、Hermes、Gemini、Kiro、Copilot、Pi、Zcode 等多個 CLI 環境，把想法轉成已驗證的程式碼庫。
