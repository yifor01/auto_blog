📌 【Google 開源】agents-cli：讓你的 Coding Agent 變身 Gemini 企業級代理開發專家

TL;DR：透過為 Coding Agent 注入專屬技能，簡化在 Gemini Enterprise Agent Platform 上建構與部署代理的流程。

如果你習慣使用 Claude Code 或 Codex 等 AI 助手來寫程式，你可能發現當涉及到特定雲端平臺（如 Google Cloud）的複雜部署與治理時，AI 往往需要你手動餵入大量檔案或指令。Google 推出的 `agents-cli` 旨在解決這個問題：它不是讓你直接操作，而是讓你的「AI 助手」學會如何操作。

🧩 **將開發能力「注入」給 Coding Agent**

`agents-cli` 並非傳統意義上的開發工具，而是一套為 Coding Agent 設計的指令與技能集。它讓 AI 助手（如 Antigravity CLI、Claude Code 或 Codex）能夠直接掌握建構、擴充套件、治理與最佳化企業級代理（Enterprise-grade agents）的能力，開發者不再需要記憶所有複雜的 CLI 指令或服務細節。

🧩 **四大核心技能模組**

透過 `agents-cli`，Coding Agent 可以習得以下四個維度的專業知識：

- **開發生命週期 (Workflow)**：掌握開發流程、程式碼儲存規則以及模型選擇。
- **ADK Python API (ADK-code)**：學習如何使用 ADK 進行代理、工具、編排 (Orchestration)、回呼 (Callbacks) 與狀態管理。
- **專案腳手架 (Scaffold)**：執行專案的建立 (create)、增強 (enhance) 與升級 (upgrade)。
- **評估方法論 (Eval)**：學習相關的評估指標與評估方法。

🛠️ **快速上手流程**

該專案要求環境安裝 Python 3.11+、uv 以及 Node.js。安裝方式分為兩種：

1. **完整設定**：執行 `uvx google-agents-cli setup`。
2. **僅安裝技能**：執行 `npx skills add google/agents-cli`，隨後由 Coding Agent 接手後續處理。

安裝完成後，開發者只需對 AI 助手下達自然語言指令（例如：「使用 agents-cli 建立一個能將冗長文字壓縮成簡短技術低吼聲的原始人風格代理」），AI 即可呼叫相關技能完成建構。

🎯 **實務啟示**

這代表 AI 開發模式的轉移：從「人類學習工具 $\rightarrow$ 指令 AI 寫碼」，轉向「讓 AI 學習工具 $\rightarrow$ AI 獨立完成建構與部署」。對於工程師而言，這能大幅降低進入 Google Cloud 代理開發的門檻，將重心從「學習 API」移至「定義代理行為」。
