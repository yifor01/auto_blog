📌 本週AI雜記：介面、搜尋與27B黑馬模型

TL;DR：Simon Willison 彙整三則值得工程師注意的動態：UI 變便宜、ChatGPT 搜尋悄悄改版、小模型打平旗艦分數。

你電腦裡是不是也躺著十幾個只有自己會用的 CLI 小工具？以前懶得幫它們做介面是因為劃不來，但這個成本假設，可能已經不成立了。

🤔 為什麼你該把 CLI 做成真正的 App

Thomas Ptacek 在文章中主張，即使是最小的個人工具，也值得做出真正的原生使用者介面，因為 coding agent 已經把「做出一個堪用 GUI」的成本壓到接近零。Simon Willison 對此深有同感，他在今年三月用 vibe coding 做出的頻寬與 GPU 監控 macOS 工具列 App，至今仍每天在用。他也坦言自己還沒把這個習慣套用到其他專案上，但直言「你已經找不到理由不做了」。對於手上一堆自用 CLI 的工程師來說，這是一個值得認真考慮的訊號：把某個丟棄式工具重做成原生 App，可能會改變你對「值不值得做介面」這件事的判斷。

🧩 ChatGPT 搜尋引擎正在悄悄改版

專門追蹤生成式引擎最佳化（GEO，Generative Engine Optimization，也就是聊天機器人版的 SEO）的 Promptwatch，觀測到 ChatGPT Search 在 fanout 查詢中使用 site: 操作符的比例，從原本 0.3% 至 0.5% 的水準，在 8 月 8 日跳升到 16% 至 17%，時間點與 GPT-5.6 Sol 的上線吻合。OpenAI 在 8 月 6 日的公告中僅模糊提及「讓 Chat 中的 GPT-5.6 Sol 在事實查核上更可靠、回答更聚焦」。Willison 觀察 ChatGPT 的實際行為後推測，新的搜尋工具形狀比較像是 search(query, recency, domains) 這樣的參數化呼叫，而非直接鼓勵模型自己寫 site: 語法。他也提到 Promptwatch 在 8 月 18 日的後續報告中指出，ChatGPT 搜尋引用 Reddit 的比例明顯下降，但他自己嘗試比對洩漏的系統提示詞集合，尚未找到對應的修改紀錄。

📊 27B 打平旗艦模型的 Qwen 3.8

Qwen 3.8 27B 在 Artificial Analysis Intelligence Index 拿下 52 分，與 GPT-5.6 Luna（max）打平，只落後 GLM-5.2（max）與 DeepSeek V4 Pro 0813（max）各一分。對照之下，那款 GLM 有 753B 參數，DeepSeek 有 1.7T 參數，而 Luna 的參數量雖然未知，但體型推測遠大於 27B。Willison 用「truly astonishing」來形容這個結果，一個能在一般規格筆電上跑起來的 27B 模型，交出跟數十倍甚至上百倍參數量模型相近的分數，對於重視本地部署與推論成本的工程團隊會是很有吸引力的訊號。

💡 其他值得記一筆的動態

- Mojo🔥 正式以 Apache 2 授權釋出編譯器與工具鏈原始碼，兌現了自 2023 年就承諾的開源計畫；不過官方也已在 2025 年 8 月改口，不再堅持讓 Mojo 成為 Python 的完整超集，而是承認它正走向一門獨立語言，靠 AI 輔助工具協助既有 Python 程式碼遷移。
- DeepSeek V4 Pro 0813 已透過 API 上線（Willison 是連到 OpenRouter，因為 DeepSeek 官方沒有明顯的公告頁面），後續開放權重確認為 1.7T 參數、893 GB，且他發現這個模型在 low、medium、high 三種推理強度下，生成內容的風格差異明顯大於他測過的其他模型。
- 404 Media 用一顆 AirTag 追蹤一批稀有書籍訂單，最終確認送達 Amazon 位於拉斯維加斯東北方的 LAS8 園區 VGT3 分區，該區被員工證實會「破壞式掃描」大量書籍，呼應了先前業界對書商收到大量匿名訂單、疑似供 AI 訓練用途的傳聞。
- Doug Turnbull 提出一個標籤分類的取巧解法：與其把上千個既有標籤餵給 LLM 要它選，不如讓模型先「憑空想像」出合適的標籤，再用向量嵌入比對出語料庫裡最接近的既有標籤。

⚠️ 這些觀察都有前提要留意

Promptwatch 的 site: 操作符數據只反映他們有開啟自動追蹤的那批 prompt，並非 ChatGPT 全量流量的真實比例；DeepSeek 的基準測試數據則是經過官方 WeChat 群組、Reddit（貼文後來被版主以「低品質」刪除）、Hacker News ASCII 表格輾轉流傳而來，可信度需要打折扣。

🎯 實務啟示

如果你手上有閒置的 CLI 工具，vibe coding 的低成本可能值得你花一個下午試著做出原生介面；如果你的產品仰賴在 ChatGPT 等聊天機器人中被引用，site: 操作符使用率的變化代表 GEO 策略需要跟著調整；而 Qwen 3.8 27B 的成績則提醒團隊，在選擇本地部署模型時，參數量不再是效能的唯一保證。
