📌 用 AI agent 補完三分之一天空,畫出第一張完整紫外線全天圖

TL;DR:Johns Hopkins 天文學家與 Claude Science 合作,用多 agent 協作補完了人類從未觀測過的紫外線天空。

天文學家習慣在課堂上展示:同一片星空,換一個波長去看,風景完全不同。可見光看到的是星星,紅外線看到的是銀河面上的塵埃,電波看到的是孕育新恆星的氫氣。但只要換到紫外線,過去能拿出來講的地圖永遠是一張「破洞的地圖」。

🤔 **為什麼從來沒有一張完整的紫外線全天圖**

紫外線會被大氣層中的臭氧吸收,想觀測宇宙的紫外線,必須靠太空望遠鏡。過去 50 年,最大的資料來源是 NASA 的 GALEX 任務(2003 到 2013 年運行),以約 38,000 次個別觀測,拍下了大約三分之二的天空。但 GALEX 刻意跳過了亮星密集的區域,包括銀河盤面本身,因為太亮的星光有可能損壞衛星感測器。NASA 的 Swift 與南韓的 FIMS/SPEAR 等任務補上了部分資料,但缺口依然存在。

要用統計方法把缺失的部分補齊,理論上做得到,但需要在逐個像素層級進行精密校準與反覆分析,耗時數週。這類工作重要卻不緊急,很容易被排在研究清單的末尾,久久沒有人去做。

🧩 **Claude Science 怎麼帶著一群 AI agent 把地圖補完**

Johns Hopkins 大學天文學家 Brice Ménard(同時也是 Anthropic 的研究者)這次用 Claude Science 來處理這個任務,指令說起來簡單,做起來繁瑣:蒐集所有公開的紫外線資料集,統一尺度,合併成一張圖,再把從未被任何紫外線望遠鏡觀測過的區域補上。

Claude 指揮一組 AI agent 分工完成:
- 先在網路上蒐集公開的紫外線觀測資料,包括 GALEX 的數萬張影像;
- 讓多個 agent 平行處理不同天區,校正亮星造成的「眩光」問題,使同一份資料內部一致(就像地面拍照時路燈或太陽造成的反光,需要先去除才能看清暗處細節);
- 把不同望遠鏡、不同解析度、不同座標系統的資料彼此交叉校準,統一到同一套座標與解析度後再合併成一張圖;
- 針對從未被觀測過的三分之一天空,使用稱為 inpainting 的機器學習技術補齊:利用已觀測的三分之二天區,學習紫外線亮度與可見光、紅外線、電波等其他波段之間的關係,再把這個關係套用到未觀測區域,同時給出每個預測點的信心程度;
- 最後在這層補齊的背景之上,疊加超過 1 億顆個別恆星的紫外線亮度估計值,這些估計是由歐洲太空總署 Gaia 衛星的可見光觀測資料推算而來。

📊 **預測準確度落在實際量測值的 10% 以內**

為了驗證補齊的可靠性,研究者故意在已有紫外線資料的區域人為「挖洞」,讓模型在看不到真實數值的情況下嘗試還原。經過多輪調整,模型估算出的數值與真實量測值相差約在 10% 以內,人眼幾乎難以察覺差異。最終完成的地圖,每個像素都標註了「實測」或「預測」,並附帶不確定性估計。

💡 **兩輪 agent 審查都沒抓到的小瑕疵,靠人眼一次看出**

地圖並非一次到位。Ménard 某天晚上檢視處理後的影像時,在較暗的天區發現一圈圈比周圍略亮或略暗的淡淡圓形痕跡,那正是每一次 GALEX 個別觀測留下的「足跡」:每張 GALEX 影像覆蓋一塊圓形天區,若地球大氣層造成的紫外線背景光沒有被完全扣除,就會在影像邊界留下輕微的亮度差。

這其實是 Claude 在專案一開始就列為已知風險的問題,但地圖卻先後通過了另外兩輪 agent 審查都沒被抓出來,直到 Ménard 親自指出「我看到帶著個別觀測痕跡的圓盤,能修正嗎?」,agent 才回頭追出問題根源,出在殘留的大氣層背景光未被完全移除。

⚠️ **AI 審查不是萬靈丹**

這個小插曲提醒,即便有多個 agent 分工並互相審查,仍可能漏掉需要領域直覺才能察覺的異常。最終抓出問題的,還是天文學家本人盯著影像時的那一眼。

🎯 **實務啟示**

對研究者而言,這個案例的價值不只在於產出一張地圖,更在於示範了一種工作模式:那些「重要但永遠排不進優先順序」的基礎工作,如今可以透過多 agent 協作在合理時間內完成,但人類專家在審查環節的角色依然不可或缺,尤其是那些統計上合理、卻在視覺或物理直覺上「怪怪的」的瑕疵。
