📌 **Goose：基於 Rust 的本機 AI Agent，整合 MCP 與 15+ 模型**

TL;DR：Linux Foundation 推出的 Goose 是跨平臺本機 AI Agent，支援 CLI、桌面版與 API，並透過 MCP 標準整合 70+ 擴充功能。

🧰 **不只是寫程式的 AI 助手**

雖然許多 AI 工具聚焦於程式碼生成，但 Goose 定位為「通用目的」的本機 AI Agent。它強調執行在你的機器上（On your machine），適用於程式碼、工作流程、研究、寫作、自動化及資料分析等多種任務。這種設計讓開發者可以在本機環境中統一管理各種 AI 輔助需求，而不必依賴分散的雲端工具。

🛠️ **原生 Rust 實作與多平臺支援**

Goose 採用 Rust 編寫，旨在提供高效能與良好的可移植性。它提供了三種主要的使用介面，以適應不同工作場景：
- **Desktop App**：提供 macOS、Linux 和 Windows 的原生桌面應用程式。
- **CLI**：完整的命令列介面，適合終端機工作流。
- **API**：提供應用程式介面，方便開發者將其嵌入到其他系統中。

這種多介面設計讓使用者可以根據習慣選擇最舒適的操作模式，無論是喜歡滑鼠操作的桌面使用者，還是偏好鍵盤快捷鍵的開發者都能上手。

🔌 **廣泛的模型與擴充套件生態系**

Goose 的核心優勢在於其靈活的後端支援與標準化的擴充套件協議：
- **多供應商支援**：內建支援超過 15 個 AI 供應商，包括 Anthropic、OpenAI、Google、Ollama、OpenRouter、Azure、Bedrock 等。使用者可以使用 API keys，或是透過 ACP 連線現有的 Claude、ChatGPT 或 Gemini 訂閱方案。
- **Model Context Protocol (MCP)**：Goose 透過 MCP 開放標準，連線超過 70 種擴充功能（Extensions）。這意味著它可以輕鬆存取外部工具、資料來源或服務，擴大了 Agent 的能力範圍。

🏛️ **Linux Foundation 背書**

Goose 屬於 Agentic AI Foundation (AAIF) 的一部分，而 AAIF 隸屬於 Linux Foundation。這顯示了該專案在社群治理與長期維護上的承諾，對於企業使用者而言，這是一個降低技術債風險的重要因素。

🎯 **實務啟示**

對於尋求將 AI Agent 整合到現有開發流程的工程師來說，Goose 提供了一個標準化的入口點。其對 MCP 的支援特別值得關注，因為這正在成為連線 LLM 與外部工具的關鍵標準。如果你需要在本機執行一個能切換多個模型、並能輕易擴充套件功能的 Agent，Goose 是一個值得評估的選擇。
