📌 前 Yandex 搜尋主管拿下 2600 萬美元種子輪，要蓋給 AI Agent 用的搜尋引擎

TL;DR：新創 Keenable 建置逾千億份文件的網頁索引，透過 API 供 AI agent 檢索使用。

搜尋引擎是為了「沒空看完整頁」的人類設計的，但當使用者換成能一口氣讀完大量資訊的 AI，這套基礎設施還適用嗎？曾主導 Yandex 搜尋、AI 與雲端部門的 Andrey Styskin 認為答案是否定的。

🤔 為 AI 重新設計網路索引

Styskin 與德國 AI 科學家 Matthias Petri 共同創辦 Keenable，公司近期正式脫離隱身模式，並宣布取得 2600 萬美元種子輪融資，由 Accel 領投，Conviction Partners 與部分天使投資人跟投。Styskin 表示，AI chatbot 若能以來源文件佐證回應，效果會明顯更好，「這其實創造出一個和 Google 從人類行為中學習截然不同的新飛輪。」

🧩 逾千億文件的索引與 API

Keenable 表示已建置一個涵蓋超過 1000 億份文件的網頁搜尋索引，其 API 已在多家 AI 實驗室與推理服務商的生產環境中用於訓練與執行階段（客戶名單未公開）。公司近期也與語音 AI 公司 Gradium 建立合作，支援即時資訊檢索。Styskin 以他在 Yandex 與 Amazon 累積的 20 年搜尋基礎建設經驗指出，Keenable 與企業內部搜尋方案的差異在於：「如果你不針對特定任務微調索引結構，掃描整個網路的成本會非常龐大。你需要根據查詢快速縮小搜尋空間，這正是我們帶到市場上的東西。」公司即將推出的產品 Web Query Language，將協助 AI 系統整合多個網頁來源的資訊來回答問題，即使沒有任何單一來源包含完整答案。

📊 融資與團隊規模

這輪融資由 Accel 合夥人 Zhenya Loginov 主導。他指出，Google 與 Microsoft 正逐步關閉既有的搜尋 API 以避免自我蠶食，轉而採取更「綁定」的策略,並對合作夥伴更加挑選，這讓 AI 業者在 web-scale 搜尋基礎建設上的選擇非常有限。Keenable 目前擁有 15 名分布於美國與歐洲的工程團隊成員，計畫用這筆資金在年底前將團隊規模擴增一倍，以建立市場推廣能量。

💡 賭注來自 Amazon 與 Alexa 的經驗

Styskin 這項判斷部分源自他在 Amazon 與 Petri 共同開發 Alexa 等 AI 應用網頁搜尋基礎建設的經驗，加上他曾看過 Cloudflare 的數據，顯示 AI 爬蟲在搜尋流量中的佔比正持續上升。目前該領域已有 Brave、Exa 等其他玩家進場，Google 自身也在為 AI 時代重新打造搜尋體驗——這些動向也印證了 Styskin 的判斷：無論對人類還是對 agent，「十條藍色連結」的搜尋時代可能正在走向終點。

⚠️ 成本仍是現實挑戰

Styskin 坦言，要說服使用者放棄 Google「極其困難」，但他認為在 agentic 查詢這個新戰場上，Google 並非不可撼動，小型公司仍有機會以更具成本效益的方案切入。不過打造大規模搜尋索引的成本同樣真實，他形容「別問，這非常燒錢」，公司正努力控制成本並按部就班擴張。

🎯 實務啟示

對正在打造 RAG 或 AI agent 檢索管線的工程團隊而言，Keenable 代表的是一類新興的「AI 原生」搜尋基礎建設，值得在評估即時網頁檢索方案時，將其與現有的企業搜尋方案或自建爬蟲方案並列比較。
