📌 一支 Python 檔案，自動幫你跟 600 多家資料仲介商討回隱私權

TL;DR：開源腳本 f*ck_data_brokers.py 自動生成法律格式的刪除信並寄送給 600+ 家資料仲介商，單檔案零依賴，還能接上 MCP 讓 AI agent 代勞。

作者說，他某天想幫朋友從某家資料仲介商刪除個資，對方無論怎麼要求都不處理，一肚子火之下寫出了這支工具，名字直接取成「f*ck_data_brokers.py」。

🤔 **資料仲介產業的規模問題**

根據作者的觀察，自 GPT-4 問世以來，資料仲介產業的「產能」大幅擴張：更聰明的爬蟲、更肥大的個人檔案、更多「人肉搜尋」網站冒出來。美國已有超過 600 家公司在政府登記簿上正式承認「販售個人資料」就是他們的業務，這讓他們很容易被列成清單，但要逐一申請刪除，對一般人來說工作量極大。

🧩 **一支檔案做什麼**

這是一支單一 Python 檔案、沒有外部依賴的工具，核心流程包括：

- 取得已登記的資料仲介商清單（600 家以上）。
- 以使用者所在地的法律用語，自動撰寫一份具法律效力的刪除／opt-out 信，語氣作者形容為「堅定、正確、合法，目的是不給仲介留下任何可以推託的藉口」。
- 透過使用者自己的免費信箱寄出，或產生一個 send.html 頁面，每封信附一個按鈕可直接開啟信箱、填好收件人與內文，按下寄送即可。
- 讀取仲介商的回信，判斷對方在用哪種話術，並建議下一步該怎麼回應。
- 對已讀未回的仲介商自動追蹤、提示使用者可以去哪裡申訴。

這個腳本同時也是一個 MCP server，只要在支援 MCP 的 AI 應用裡加入對應設定，就可以直接跟 AI assistant 說「用 fuck_data_brokers 幫我從資料仲介商那裡刪除資料」，讓 AI 代為詢問身分資訊、取得清單、寫信、讀取回覆並撰寫回應。作者特別強調，工具被要求在寄出任何東西前必須先詢問使用者、不得捏造使用者的個人資料、不寄送身分證件、也不點擊仲介商提供的連結。

🧩 **實際使用方式**

使用者只需要 Python 3.8 以上版本和一個 Email 地址即可開始。執行 `python fuck_data_brokers.py` 會進入選單，依序填寫姓名、Email、城市與所在地（不需要街道地址或生日），取得仲介清單、撰寫信件（一次寫 20 封）、寄送。也可以用 `python fuck_data_brokers.py auto` 全自動執行，加上 `--send` 參數並透過環境變數 `FDB_SMTP_PASS` 存放 App 密碼即可自動寄送，可以排程成每週執行一次的 cron job 或 Windows 排程工作，幾個月內就能覆蓋整份清單。遇到只接受網頁表單、不受理 Email 的仲介商，則用 `forms` 子命令產生含表單連結與可複製內容的頁面，人工過 CAPTCHA 送出後用 `sent` 標記；若表單要求上傳身分證照片，可以直接關掉分頁，並用 `noid` 告訴工具改走書面申請流程繼續跟進。

🎯 **適用場景與限制**

這支工具完全免費、在本機執行、個資留在使用者自己的電腦上。作者也提供一個付費版服務「Agent Garrett」，由他本人持續代為處理所有後續流程（包含免費版做不到的部分，使用者仍可免費自行操作）。素材中未提供與其他同類隱私工具的效能或覆蓋率比較。

🎯 **實務啟示**

這個案例示範了一種實用的 agent 設計模式：把重複性高、格式固定、但需要人工把關關鍵動作（例如寄送前必須確認）的法律流程，拆成「AI 處理繁瑣部分＋人類核准關鍵動作」的分工，並透過 MCP 把這個工作流接進任何支援 MCP 的 AI 助理，是值得參考的實作方向。
