📌 微軟新 Copilot 整合聊天、寫程式與 Autopilot 代理

TL;DR：微軟正式推出 Copilot「超級應用」，把聊天、程式撰寫與企業級代理整併進單一介面，並將 Scout 更名為 Autopilot。

微軟上個月才預告過這款產品，如今正式揭曉。新版 Copilot 應用把三種 AI 能力包進同一介面：聊天、寫程式，以及代理，執行長 Satya Nadella 甚至把它稱為「工作用的新作業系統」。

🤔 三個分頁，一個入口

新的 Copilot 應用分成 Home、Code、Autopilot 三個分頁。Home 合併了 Copilot Chat 與 Cowork，是預設的首頁體驗，內建 Today 功能，彙整重要郵件、會議邀請、Teams 討論串等，作為個人化儀表板；AI 工作事務行銷長 Jared Spataro 形容它是「讓你重新掌握狀況、接續之前工作進度的地方」。

🧩 Code 分頁是最意外的加入

Code 分頁讓任何人都能建立應用程式、追蹤器、儀表板或自動化流程，並以雲端內部應用的形式分享給同事，這在一款主打知識工作者的應用中頗為少見。Spataro 表示，Code「由與 GitHub Copilot 相同的底層技術驅動，在沙盒環境中執行，並可安全地託管在企業租戶內」。

至於 Autopilot，是先前在 Build 大會發表的 AI 個人助理 Scout 的更名與雲端化版本，Spataro 稱其為「數位隊友」，能在使用者離線時持續運作。它擁有自己的雲端運算執行個體，可用來監看 Teams 頻道、執行週期性工作、處理後續追蹤事項；它常駐在企業租戶內，具備自己的身分、記憶、運算與工作空間，並基於「Microsoft IQ」理解組織的實際運作方式，可在 Teams、Outlook、聊天、頻道與文件中被 @ 提及，並套用權限、稽核與治理機制。使用者也可以為 Autopilot 命名並自訂外觀。

📊 計費方式跟著用量走

這次改版也調整了計費模式：Cowork、Code、Autopilot 的部分改採用量計費，長時間執行的代理任務，或使用 Astra、Fable 等模型都會依用量計費；一般的 Copilot 使用者訂閱授權則涵蓋 Chat，以及 Word、Excel、PowerPoint、Outlook、Teams 內建的 Copilot 功能。微軟以自動模型選擇器依任務挑選合適模型，IT 管理者則需透過新推出的 FinOps for AI 來管理 AI 支出，避免代理用量失控。Home 與 Code 分頁將優先開放給 Frontier 搶先體驗計畫使用者，Autopilot 本月稍晚進入 private preview，Code 則預計稍後對 Microsoft 365 Premium 與 Pro 訂閱使用者開放 preview。

⚠️ 消費市場落後，競爭對手比 PC 時代更多

報導也點出，Copilot 在消費端市場的表現始終不如 Claude 或 ChatGPT，這次改版明顯瞄準企業客戶；而相較於 Office 稱霸 PC 生產力時代，如今 AI 賽道上同時有 Google、OpenAI、Anthropic 與 Meta 等強力競爭者，微軟能否靠這款「為工作打造的 AI」追上進度，仍是未知數。

🎯 給工程團隊的啟示

值得關注的是 Code 分頁：它讓「寫應用程式」變成一般知識工作者也能觸及的能力，而用量計費模式也意味著企業導入代理式 AI 時，需要及早建立內部的用量與成本治理機制（例如 FinOps for AI），而不是等帳單暴增才回頭處理治理問題。
