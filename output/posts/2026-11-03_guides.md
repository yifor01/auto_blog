📌 Simon Willison 彙整 16 篇 Coding Agent 實戰筆記

TL;DR：Simon Willison 把用 Claude Code、OpenAI Codex 等 coding agent 的實戰心法整理成 16 章指南。

當「寫程式碼」本身變得便宜,真正稀缺的能力反而換了一批。Simon Willison 在他的新系列 Guides 裡,直接把標題取成「Writing code is cheap now」,點出這個轉變正是整套指南的出發點。

🤔 **當程式碼變便宜,工程師該囤什麼**

這套指南不是單一教學,而是一組「如何讓 coding agent 產出更好結果」的模式集合。開篇幾章先談心態層：「What is agentic engineering?」定義這個新領域,「Writing code is cheap now」討論成本結構的變化,「Hoard things you know how to do」建議工程師該囤積哪些經驗資產,「AI should help us produce better code」把目標拉回「品質」而非單純「速度」,再搭配一章「Anti-patterns: things to avoid」,列出該避開的錯誤用法。

🧩 **從原理到日常協作流程**

接下來三章轉向機制層面：「How coding agents work」解釋這類工具的運作原理,「Using Git with coding agents」談版本控制如何與 agent 協作,「Subagents」則聚焦多個 agent 分工的用法。

🧪 **把測試習慣搬進 agent 流程**

指南中有連續三章專門談測試：「Red/green TDD」把經典的測試驅動開發節奏套進 agent 工作流,「First run the tests」強調動作順序的重要性,「Agentic manual testing」則討論如何讓 agent 協助執行人工測試。

💡 **溝通與說明的技巧**

「Linear walkthroughs」與「Interactive explanations」兩章聚焦在如何呈現、說明程式變更過程,幫助讀者或協作者更容易跟上 agent 的推理與產出。

🎯 **兩個實戰案例與一份 Prompt 清單**

指南最後用兩個具體案例收尾：一個是「用 WebAssembly 與 Gifsicle 打造的 GIF 最佳化工具」,另一個是「為部落格轉電子報工具加入新內容類型」的實作紀錄,展示如何把前面的原則用在真實專案上。最後一章「Prompts I use」直接公開作者常用的 prompt。

🎯 **實務啟示**

對日常使用 coding agent 的工程師來說,這套指南提供的不是單一技巧,而是一整套可以對照自己工作流程逐章檢視的清單:從心態設定、Git 協作、測試節奏到如何說明變更,都是可以直接拿來對照、調整自己 agent 工作習慣的素材。
