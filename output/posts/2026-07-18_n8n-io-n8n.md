TL;DR：n8n 是 fair-code 自動化平臺，結合視覺化流程與程式碼，可自建或上雲跑 AI agents。

工程團隊想要匯入 AI 自動化，卻不想被單一模型供應商綁死，也不想放棄既有的 1500 多個系統整合——n8n 正是衝著這個缺口設計的。

🤔 **給需要兼顧視覺化與彈性的自動化團隊**

n8n 是由 n8n-io 維護的 fair-code 平臺，定位為「AI agents 與工作流自動化的執行環境」。它讓使用者在視覺化 canvas 上編排流程，同時能在需要時寫入自訂程式碼，並選擇自託管（self-hosted）或雲端部署，連線超過 1500 個整合。

🧩 **AI 原生但講求不鎖死模型**

README 指出，n8n 的核心設計包含幾項能力：

- AI-Native Automation Platform：用自有資料、模型與工具，建構並運作 AI 工作流與多步驟 agents。
- Model Flexibility, No Lock-In：可連線 OpenAI、Anthropic、Google 或開源模型，切換供應商時不需改動架構。
- From Prototype to Production：設計多步驟 AI 工作流，內含邏輯判斷、tool use、人工審核與完整可觀測性（observability）。
- Code When You Need It：視覺化編排可搭配 JavaScript、Python 與 npm 套件處理進階流程。
- Enterprise-Ready AI：自託管或安全部署，具角色許可權、稽核軌跡與敏感資料支援。
- Leverage What Already Exists：提供 1500+ 整合與 9000+ 工作流範本，銜接現有系統。

💡 **兩種方式立刻試跑**

README 提供的最小可行啟動方式如下：

- 使用 npx（需先安裝 Node.js）：執行 `npx n8n`
- 使用 Docker：
  - `docker volume create n8n_data`
  - `docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n`
- 啟動後在瀏覽器開啟 `http://localhost:5678` 即可進入編輯器。
