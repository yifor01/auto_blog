📌 **DreamServer：一鍵本地AI主權平台**

你每一次向雲端AI發問，都在交出資料與控制權？DreamServer 讓你在自家機器上擁有完整AI堆疊，不用訂閱、不用雲端。

🤔 **為何需要自我主權的AI？**  
目前全球大部分AI流量被少數雲端供應商壟斷，這意味著你的查詢成為他們的業務智慧，運行在你無法掌握的基礎設施上，費用與可用性也受制於對方條款。當AI逐漸成為基礎設施時，依賴租用模式是否仍屬合理？

🧪 **一鍵部署的本地AI堆疊**  
DreamServer 是一個「local‑first」AI平台，透過單一指令即可在自己的硬體上安裝並運行：LLM 推論、聊天、語音、代理人、工作流程、RAG、圖像生成以及隱私工具。支援平台包括：  
- Linux（NVIDIA + AMD + Intel Arc）  
- Windows（NVIDIA + AMD，需搭配 Docker Desktop 的 WSL2 後端）  
- macOS（Apple Silicon）  
已測試的 Linux 發行版：Ubuntu 24.04/22.04、Debian 12、Fedora 41+、Arch Linux、CachyOS、openSUSE Tumbleweed；其他使用 apt、dnf、pacman 或 zypper 的發行版預期也相容。

🚀 **核心功能：擁有、掌控、不受監視**  
- **無需雲端**：所有運算在本地完成，資料不離開你的機器。  
- **無訂閱費**：一次安裝，長期使用不產生額外費用。  
- **可選雲端混合模式**：若需要，可選擇啟用雲端或混合 API，但非預設行為。  
- **隱私導向**：內建工具幫助你管理資料存取與使用紀錄。

💡 **為何這個專案對開發者與隱藏用戶具有實際價值？**  
它將多個已存在的開源元件（LLM 引擎、語音合成、圖像生成等）打包成一致的體驗，降低自行組裝的複雜度。對於關心資料主權、希望避免供應商鎖定或在網路受限環境中工作的使用者來說，這提供了一條可立即採用的路徑。

⚠️ **已知限制**  
- 需要符合硬體條件的 GPU（NVIDIA、AMD 或 Intel Arc）才能獲得良好推論效能。  
- Windows 部署依賴 Docker Desktop 與 WSL2，額外安裝步驟可能對非開門使用者造成門檻。  
- 目前說明文件僅提供安裝與基本使用指引，進階效能調校或特定模型微調需參考相關元件的原始文件。
