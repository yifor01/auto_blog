📌 Salesforce 推出 Headless Data 360 for MCP，把治理資料直接餵給 agent

TL;DR：Salesforce 讓開發者能透過 MCP，把受治理的客戶資料直接接進 agent。

Agentic AI 的運作根基是資料，這句話說起來簡單，但真正落地時卡住多數團隊的往往是「資料要怎麼安全地送到 agent 手上」。

🤔 **資料治理與 agent 存取之間的落差**

Salesforce 宣布推出 Headless Data 360 for Model Context Protocol，目的是把相關、且受治理的客戶情境資料，直接提供給 agent 使用。透過這項功能，團隊得以讓 agent 存取具備治理層級控管的資料，而不必自行搭建一套資料存取與權限管理的中介層。

💡 **聚焦在既有生態系內的整合**

從目前公開的資訊來看，這次發布屬於 Salesforce 產品線在資料存取層的功能擴充，將 MCP 這個逐漸成為 agent 與工具間標準溝通協定的介面，接進 Salesforce 既有的 Data 360 治理框架。更完整的技術細節與適用場景，目前的素材尚未提供。

🎯 **實務啟示**

如果你的團隊本身就在 Salesforce 生態系內建置 agent，這代表你多了一條經過治理把客戶資料接進 agent 的路徑，值得留意後續官方釋出的技術文件，確認實際的整合方式與存取控管機制是否符合你的合規需求。
