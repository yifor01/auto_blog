📌 把 LLM 畫的動畫 SVG 轉成 MP4：Simon Willison 的瀏覽器端小工具

TL;DR：markdown-svg-renderer 讓你直接在瀏覽器把 Markdown 裡的 SVG（含動畫）轉存成 PNG、JPEG 或 MP4 方便分享。

如果你也常常拿「畫一隻騎腳踏車的鵜鶘」這類 SVG 生成題來測試 LLM，很快就會遇到一個尷尬的現實：多數社群平臺根本不支援直接顯示 SVG，更別說 SVG 動畫了。Simon Willison 從 5 月開始打造的 markdown-svg-renderer，就是為了解決這個問題而生的工具，如今功能已經累積到值得再寫一篇介紹。

🤔 問題：SVG 很好用，但分享起來很麻煩

Simon 提到自己因為經常畫「鵜鶘騎腳踏車」這類 SVG 測試題，需要一個工具來分享包含 SVG 文件的 Markdown 逐字稿（transcript）。這個工具因此逐漸演變成他理想中「分享含 SVG 內容的 Markdown」的解決方案。

🧩 怎麼用：貼上 Markdown，或給一個網址

工具本身的使用方式很簡單：打開瀏覽器上的 markdown-svg-renderer 頁面，直接貼上 Markdown 內容即可看到渲染結果；也可以把 Markdown 存到一個支援 CORS 的網址，或存成 GitHub Gist，貼上該網址讓工具讀取。這種網址模式還有一個好處，就是會產生一個可加入書籤（bookmarkable）的頁面，網址本身就把來源網址編碼在其中（例如以 #url= 參數帶入一個 GitHub Gist 連結）。當 Markdown 裡有一段原始 SVG 內容時，在工具裡會被轉換成實際渲染出來的 SVG（如果是動畫 SVG，也會呈現動態效果），並且提供多個分頁。

其中 PNG 與 JPEG 分頁，是把該 SVG 在瀏覽器內即時轉成對應的圖片格式，讓使用者可以複製或下載，這對於要在不支援 SVG 的平臺上分享很有用。而新增的 MP4 分頁則更進一步：它會先檢查該 SVG 是否包含動畫，嘗試推算這段迴圈動畫該有的長度，接著渲染出一連串動畫畫格，再載入超過 30MB 的 ffmpeg.wasm，利用編譯成 WebAssembly、直接在瀏覽器裡執行的完整 FFmpeg，把這些畫格編譯成一支 MP4 影片。

💡 一個小工具，展現的是瀏覽器端運算的能耐

把動畫 SVG 轉成 MP4，讓原本無法在多數平臺原生播放的 SVG 動畫，也能用影片格式分享出去。這整個轉檔過程——從畫格擷取到 FFmpeg 編碼——完全在瀏覽器端完成，不需要伺服器端運算，是 WebAssembly 讓重量級工具（如 FFmpeg）得以搬進瀏覽器執行的一個具體例子。

🎯 實務啟示

如果你的工作經常需要展示或分享 LLM 生成的 SVG 圖形（例如評測不同模型的視覺化輸出能力），這類零後端、純瀏覽器端的轉檔工具，比起自己架設轉檔服務要輕量得多；也提醒我們在設計類似工具時，可以善用 CORS 友善網址與 URL 參數編碼，讓輸出結果能直接生成可加入書籤、可分享的連結，省去額外的儲存與部署成本。
