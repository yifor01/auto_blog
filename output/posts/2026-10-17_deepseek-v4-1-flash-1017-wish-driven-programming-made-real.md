📌 DeepSeek 最新發布:讓「願望」直接變成完整專案

TL;DR:DeepSeek 推出 V4.1-Flash-1017,主打端到端專案生成更快、更省,效能與成本同步提升。

如果你只需要打一句話,AI 就能幫你生出一座紫禁城的 3D 模型,甚至重現一款賽車遊戲,你會怎麼用這個能力?DeepSeek 把這個情境稱為「Wish-Driven Programming」,並在最新模型 V4.1-Flash-1017 中將它變成現實。

🤔 從「寫程式碼」到「完成專案」的門檻在哪裡

多數 coding agent 停留在產生片段程式碼,真正從頭到尾完成一個可執行專案,例如遊戲、3D 場景或互動式應用,仍需要大量人工銜接。DeepSeek 這次更新的訴求,是讓模型能一次性扛起「端到端專案開發」,官方公告就展示了四個範例:紫禁城的 3D 建模、一款網頁版賽車遊戲、用 Godot 引擎重建的《Portal 2》,以及一個描繪從史前時代走到現代的 3D 場景「Valley of Ages」。

🧩 用強化學習配合自我回饋機制

官方說明 V4.1-Flash-1017 採用「reinforcement learning with self-feedback」來提升端到端專案開發的品質,也就是模型在產出過程中會對自身結果進行回饋與修正,而非單純一次性生成。此版本針對 DeepSeek Harness、Tencent CodeBuddy、WorkBuddy 等工具做了最佳化,官方建議將 DeepSeek Harness 升級到 v0.2.1-rc.1 以上版本,才能取得最佳使用體驗。

📊 效能、速度、輸出長度三個方向同時進步

官方描述這次更新是「效能與成本的帕累托改善」:相較前一版本,benchmark 表現更強、任務完成速度更快、輸出也更短。此外,DeepSeek 也將自家搜尋引擎能力包裝成 Search 與 Fetch 兩個伺服器端工具,每個 endpoint 收費為每千次呼叫 0.75 美元,官方表示這套搜尋引擎每天在全球處理數億次請求。值得注意的是,透過 DeepSeek Harness、Claude Code 或 Codex 呼叫這兩項工具,目前對 DeepSeek API 使用者是免費的,計費將從 2026 年 10 月 31 日 16:00 UTC 開始。

⚠️ 公告未附具體對比數據

這次發布並未揭露實際 benchmark 分數與對比基準,「更強」「更快」「更短」皆為官方定性描述,實際表現落差仍需等待社群或第三方的獨立測試驗證。

🎯 實務啟示

對於正在評估 coding agent 的工程團隊,這次更新值得關注的不只是模型本身,而是 Search/Fetch 工具可在 Claude Code、Codex 等既有工作流中免費試用到月底,等於是低成本驗證「搜尋增強型」程式碼生成是否符合自己場景的窗口。
