📌 【Anthropic 官方發布】把 Agent Skills 標準捐給 Linux Foundation

TL;DR:Agent Skills 開放標準捐贈給 Agentic AI Foundation,70 多個平臺已整合,安裝量近 2.8 億次。

一個標準,從內部工具長成被 70 多個平臺採用、安裝次數逼近 2.8 億的開放規格,通常下一步是廠商把它緊緊抓在手裡當護城河。這次 Anthropic 選擇反過來,把主導權交出去。

🤔 **從 Claude Code 的痛點長出來的概念**

Anthropic 表示,他們在打造 Claude Code 時發現,模型處理一般知識工作表現不錯,但常常缺乏真實業務任務所需的「程序性知識」。為了補上這塊,他們發展出 skills 的概念:一個 skill 就是一個包含 SKILL.md 檔案的資料夾,教會 agent 特定任務或領域的做法,連同它需要的腳本與參考資料。

🧩 **從內部工具到開放標準**

2025 年 10 月發布後的短短幾週內,開發者就在 GitHub 上發布了數千個 skills,並自行為 Codex、Cursor、OpenCode 寫了對應的 loader。看到這股自發熱度後,Anthropic 接著在 2025 年 12 月把 Agent Skills 獨立發布為開放標準,擁有自己的 GitHub 組織與 agentskills.io 網域,讓任何 agent 平臺都能使用。

📊 **70 多個平臺,近 2.8 億次安裝**

截至目前,包括 ChatGPT、Cursor、GitHub Copilot、VS Code 等超過 70 個 agent 平臺已整合 Agent Skills。累計已有 100 萬個 skills 被發布,安裝次數接近 2.8 億次。

💡 **捐給誰、誰來維護**

這次捐贈的對象是 Linux Foundation 旗下的 Agentic AI Foundation(AAIF),這個組織正是 Anthropic 去年與 Block、OpenAI 共同創立的,也是 Model Context Protocol(MCP)捐贈後落腳的同一個家。捐贈內容包括 Agent Skills 的名稱與 logo、GitHub 組織,以及 agentskills.io 網域。往後標準將由來自 Anthropic、Google、OpenAI 等公司的工程師以個人身份維護,David Soria Parra 與 Mahesh Murag 擔任首席維護者(Lead Maintainers)。

⚠️ **接下來還缺什麼**

Anthropic 提出的下一步規劃包含版本化發布、正式的提案流程,以及給撰寫與安裝 skills 的人的安全性指引。這些目前還是「提案」階段,尚未定案。

🎯 **實務啟示**

對已經在用或正打算導入 Agent Skills 的團隊來說,這次捐贈代表標準會持續保持開放、社群驅動、廠商中立,不用擔心未來被單一供應商的商業決策綁架。想參與規格討論的人,可以加入專案的 Discord 或在 GitHub 上提出意見。
