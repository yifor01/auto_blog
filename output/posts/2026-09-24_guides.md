📌 Simon Willison 把「怎麼跟 coding agent 合作」寫成 16 章實戰指南

TL;DR：一份專注 agentic engineering 實務模式的系列文章，教工程師如何有效駕馭 Claude Code、Codex 等 coding agent。

當「寫程式碼很便宜」成為新常態，真正稀缺的能力反而變成了「知道怎麼跟 AI agent 一起工作」。Simon Willison 把自己摸索出來的心法，整理成一套完整的指南系列。

🤔 **從「能不能生成程式碼」轉向「怎麼駕馭 agent」**

隨著 Claude Code、OpenAI Codex 這類 coding agent 逐漸成為開發者日常工具的一部分，單純「會用」已經不夠，如何建立一套可重複、可信賴的工作模式，才是真正拉開差距的關鍵。這套 Guides 正是圍繞這個核心問題展開，作者在系列介紹中稱之為「agentic engineering」。

🧩 **16 個章節，涵蓋心態、流程與實作範例**

整套指南共 16 章，內容大致可分為三個層次：

- **心態轉變類**：〈What is agentic engineering?〉〈Writing code is cheap now〉〈Hoard things you know how to do〉〈AI should help us produce better code〉〈Anti-patterns: things to avoid〉，談的是面對 coding agent 時該建立的思維框架，以及該避開的常見誤區。
- **工作流程類**：〈How coding agents work〉〈Using Git with coding agents〉〈Subagents〉〈Red/green TDD〉〈First run the tests〉〈Agentic manual testing〉〈Linear walkthroughs〉〈Interactive explanations〉，聚焦在版本控制、子代理（subagent）拆解任務、測試驅動開發、以及如何驗證 agent 產出的具體作法。
- **實作案例類**：〈GIF optimization tool using WebAssembly and Gifsicle〉〈Adding a new content type to my blog-to-newsletter tool〉〈Prompts I use〉，用真實專案示範上述原則如何落地，並附上作者實際使用的提示詞。

💡 **測試先行、版本控制與子代理是反覆出現的主軸**

從章節安排可以看出，作者格外重視「先跑測試」「Red/green TDD」以及「Using Git with coding agents」這幾個主題，暗示著在 agent 自動產出程式碼的情境下，驗證機制與版本控制紀律比以往更重要——這也呼應了〈Anti-patterns〉這一章特別點名要避開的做法。
