📌 **AionUi：零設定多代理AI協作平台**

你是否曾想過，讓多個 AI 助手同時在你的電腦上工作，卻不需要安裝一堆 CLI 工具？

🤔 **為什麼需要一個統一的 AI 代理平台**

現有的 AI 輔助工具（如 Claude Code、Codex、Qwen 等）多以獨立的命令列介面出現，使用者必須分別安裝、設定且難以在同一畫面觀察它們的行為。這種分散的使用方式增加了學習成本，也限制了代理之間的協同與遠端監控的可能性。

🧪 **零設定、即裝即用的設計**

AionUi 內建完整的 AI agent 引擎，安裝後即可使用，無需額外安裝任何 CLI 工具。它支援「任意 API Key」的接入，讓使用者可以自行決定要連接哪個後端模型。平台採用跨平台框架，提供統一的桌面 UI，同時可透過 WebUI、Telegram、Lark、DingTalk、WeChat、WeCom 等方式實現遠端存取。

🚀 **核心功能：多代理、遠端與 24/7 自動化**

- **多代理同步**：可同時啟動 Claude Code、Codex、Qwen Code、Kiro、Hermes Agent、Snow CLI、Cursor Agent 等 16+ 個已知代理，所有代理透過統一介面進行管理。  
- **完整檔案存取**：內建代理具備完整的本地檔案讀寫權限，使用者可以觀察代理對檔案的每一步操作。  
- **多步驟任務**：代理能夠自主執行多步驟工作流程，並在關鍵節點等待使用者確認。  
- **排程自動化**：內建類似 Cron 的排程機制，實現無人值守的 24/7 自動化任務。  
- **多語言支援**：介面提供 English、简体中文、繁體中文、日本語、한국어、Español、Português、Türkçe、Русский、Українська 等語言版本。

💡 **如何統一現有的 AI Agent CLIs**

AionUi 的核心在於自動偵測已安裝的各類 AI agent CLI，並將它們包裝成統一的圖形化操作元件。使用者無需學習不同 CLI 的指令語法，即可透過點選或拖曳方式啟動、監控與停止代理。這種「即插即用」的機制大幅降低了工程師將多個 AI 工具納入日常工作流程的門檻。
