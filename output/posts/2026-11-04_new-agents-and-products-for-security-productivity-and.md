📌 【Anthropic 官方公告】Claude Marketplace 再添 25+ 夥伴，企業承諾額度可直接買單

TL;DR：Claude Marketplace 新增安全、開發基礎設施、創意與生產力類別的夥伴產品，企業可用既有 Anthropic 承諾額度採購，不必另開預算。

如果你的團隊已經在用 Claude，卻還在為程式碼安全掃描、Agent 可觀測性或行銷內容產出另外採購工具、另開預算審批，Anthropic 這次更新值得注意：Claude Marketplace 的夥伴陣容擴大到超過 25 個產品與 agent，而且符合資格的企業客戶可以直接把已經承諾給 Anthropic 的花費，拿來買這些夥伴方案。

🤔 **一份承諾額度，買 Claude 也買夥伴產品**

Claude Marketplace 是企業尋找能搭配 Claude 使用的夥伴工具與服務的地方。Anthropic 這次公告的重點是：符合資格的企業客戶能把一部分既有的 Anthropic 承諾支出，直接用在這些夥伴解決方案上，不論是採購全新工具，還是擴大使用原本就在用的平臺，都能沿用同一份承諾額度，不需要為 Claude 與夥伴產品分別編列預算。

🧩 **四大類新增夥伴：安全、開發基礎設施、創意、生產力**

**程式碼與系統安全**
- Chainguard：Harness 在隔離的 microVM 中從原始碼建置應用程式，並對運行中的應用程式進行可被利用漏洞的探測，協助團隊針對可重現的漏洞提供客製化修復建議。
- Checkmarx：Checkmarx One 結合規則式分析與 AI 推理找出程式碼中的漏洞，協助團隊在程式碼上線前排定修復優先順序並完成修復。
- Cyera：Agent Guardian 盤點 Claude 的部署情況，在 Claude 執行前治理權限，並針對 prompt、檔案與工具呼叫強制執行政策，同時協助團隊透過紅隊演練（red teaming）測試這些控制機制。
- Rubrik：Code Guardian 使用 Anthropic 的前沿模型，審查 GitHub 或 Azure DevOps 儲存庫的安全副本，找出多步驟攻擊路徑，協助安全與工程團隊依嚴重程度排序問題，並把確認的重大問題轉成可追蹤的工單。
- Tanium：Tanium Cloud 提供跨端點的即時可視性與控制能力，協助 IT 與安全團隊找出並修補漏洞、設定錯誤與缺失的修補程式。

**工程團隊的開發基礎設施**
- Datadog：Agent Observability 追蹤 agent 透過工具與服務執行的過程，透過呈現生產環境中的模式並提出建議，協助團隊提升 agent 的品質、效能與成本效率。
- Netlify：Enterprise 方案能將用 Claude 建構的應用程式、網站與 agent 部署到全球邊緣網路，每次變更都附帶預覽網址，並內建 SSO、角色型存取控制與稽核日誌，讓團隊從原型走到生產環境時不需要額外設定基礎設施。

**行銷與創意工作工具**
- AirOps：提供 AI 搜尋策略、內容與多管道執行的 agentic 平臺，協助行銷團隊分析品牌在 AI 搜尋中的表現，並將結果與業務漏斗、營收連結。
- Runway：生成與編輯影片、圖片與音訊，協助創意與行銷團隊把一份簡報轉成完成品，並用自然語言編輯影像素材。
- Webflow：提供建置、管理與最佳化網站的內建工具，協助行銷人員、設計師、工程師與 agent 一起進行變更，同時內建控制與治理機制。

**各團隊的生產力應用**
- Asana：AI Teammates 是預先建置好的 agent，使用 Asana Work Graph 中的情境資訊，各自擁有獨立身分、範圍受限的權限與稽核軌跡，協助處理多步驟工作，並把需要判斷的決策導向負責人。
- Glean：串連公司內部跨系統的知識與工作流程，協助員工在已連結的應用程式中找到答案並完成多步驟任務。
- monday：agent 在專案、看板、文件與會議中運作，以負責人與期限等既有資訊作為情境，協助 PMO、IT、行銷、財務與營運團隊控制 AI 可以存取、核准與花費的範圍。
- Zoom：Agentic Search 讓使用者能在 Claude 中直接利用最新的會議摘要、工作對話、文件與已連結的第三方來源回答問題，團隊可取得具權限意識（permission-aware）的結果，不需要逐一分析原始逐字稿或自行串接多個工具。

🎯 **實務啟示**

對已經在企業內導入 Claude 的工程與安全團隊而言，這批新增夥伴的意義在於「省去重新採購流程」：原本要單獨談合約、單獨審預算的程式碼安全掃描（如 Checkmarx、Rubrik）、agent 可觀測性（Datadog）或部署基礎設施（Netlify），現在能直接併入既有的 Anthropic 承諾額度。如果你的團隊正在評估 agent 安全治理或程式碼漏洞掃描工具，值得先確認公司的 Anthropic 合約是否適用這項額度彈性，再決定是否要另外走採購流程。
