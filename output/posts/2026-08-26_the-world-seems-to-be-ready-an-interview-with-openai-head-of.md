📌 OpenAI 產品負責人談 ChatGPT Work：把 Coding Agent 包裝給所有人用

TL;DR：OpenAI 產品長 Thibault Sottiaux 談 ChatGPT Work 的定位、定價與擴散策略。

Codex 原本只服務願意忍受早期 bug 的技術死忠使用者，如今 OpenAI 想把同一套 agent 能力，包裝成月費 20 美元、任何白領工作者都能上手的產品。負責這件事的人是 Thibault Sottiaux。

🤔 從技術死忠粉到大眾市場

Sottiaux 目前負責 OpenAI 所有核心產品線，包括 API、agent 基礎設施、企業產品、整個 ChatGPT（涵蓋 ChatGPT Work 與傳統版 ChatGPT），以及 Codex，直接向 Greg Brockman 匯報。他表示 ChatGPT Work 的核心目標，是把原本為技術族群打造的 coding agent 能力，包裝成安全、令人愉悅且可在手機與網頁上隨手使用的形式，盡可能推向最廣泛的族群，因此選擇以 Plus 方案（每月 20 美元）的一部分推出。

🧩 用「發現」取代「規劃」的產品哲學

被問及如何思考產品邊界時，Sottiaux 表示自己並不是先設定好一個「最小可行產品」的框架，而是隨著模型能力的前沿推進,不斷發現模型真正擅長什麼，再據此打造產品並持續蒐集回饋、迭代改進。他舉例，GPT-5.6 在一般辦公工作上有明顯進步，能處理大量文件、產出高品質簡報與報告，並執行深度研究等專業人士日常會做的任務,這些發現也直接反映在 ChatGPT Work 的產品方向上。

📊 兩千萬使用者與大幅降價

Sottiaux 透露 ChatGPT Work 剛達成 2000 萬使用者的里程碑。訪談中也提到 Wharton 教授 Ethan Mollick 的觀察：ChatGPT Work 試圖打造「魔法」般的體驗，相對地，Claude Cowork 則是把 A/B 測試與更多選擇權交還給使用者。在定價上，Sottiaux 提到 OpenAI 已透過 Luna 宣布大幅降價，降幅達 80%，並強調這是「永久性的價格修正」；產品端則在受訪當天同步推出 iMessage 整合功能。

💡 商業邏輯與安全疑慮的回應

Sottiaux 直言，使用者從 ChatGPT 獲得的效用越多，就越願意為其中一部分付費，這也是 OpenAI 一貫希望掌握「應用關係」的商業邏輯所在。對於使用者擔心把 Email、iMessage 等權限交給 AI 的疑慮，他表示公司在安全堆疊與對齊方法上投入大量資源，並公開誠實的 benchmark 結果，強調其模型在這方面「處於世界頂尖水準」。

必須留意，以上內容全部來自 Sottiaux 的訪談發言，反映的是 OpenAI 自身的產品敘事與願景，例如「世界已經準備好了」等說法並無獨立數據佐證，訪談本身也未揭露 ChatGPT Work 的具體技術實作細節。

🎯 實務啟示

對於評估企業導入 agent 型產品的技術團隊，這篇訪談提供的訊號是 OpenAI 正以「激進降價＋大眾化擴散」的策略,把原本鎖定開發者的 agent 能力向白領市場推進，值得持續關注其後續採用數據與實際企業導入案例，而非僅憑產品方的敘述做決策。
