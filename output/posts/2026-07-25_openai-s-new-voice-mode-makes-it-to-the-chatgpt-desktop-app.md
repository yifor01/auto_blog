📌 【OpenAI 更新】ChatGPT 桌面版新增語音模式，能透過語音操控電腦與 AI Agent

TL;DR：ChatGPT 桌面版整合 ChatGPT-Live 模型，支援語音操控電腦並執行多步驟任務。

OpenAI 正式將全新的語音模式匯入 ChatGPT 桌面應用程式，這不僅僅是更流暢的對話，更讓使用者能透過語音指令來控制 AI Agent 並在電腦上執行實際任務。

🧩 **從手機對話進化到桌面端的「電腦操作能力」**

雖然先前推出的手機版語音模式具備更流暢的對話體驗與更好的中斷處理機制，但它並未設計用於執行電腦操作。這次的桌面版更新大幅提升了功能性：

- **核心動力**：採用本月初推出的全新語音模型家族「ChatGPT-Live」。
- **多工協作**：ChatGPT Voice 能同時進行聽取、說話與協調 App 內的作業。
- **複雜指令**：使用者可以下達包含多個步驟的複雜指令，且當 ChatGPT 需要使用者確認時，它會主動回應。
- **整合能力**：支援 ChatGPT Work 與 Codex，並能利用「電腦使用（computer use）」技能來查詢網站或應用程式。

💻 **macOS 使用者的視覺感知新功能**

在 macOS 平臺上，透過 Appshots 功能，ChatGPT 可以存取螢幕上的內容，包含 alt-text（替代文字），進一步擴展了對螢幕資訊的理解能力。

📊 **實作範例：一個指令完成開發流程**

在 OpenAI 發布的演示影片中，一名開發者僅透過一個語音指令，就要求 ChatGPT 完成以下一系列動作：
1. 建立一個新 Thread（執行緒）。
2. 製作一個 Pull Request（拉取請求）。
3. 找出 Bug（錯誤）的根本原因。

此外，使用者也可以透過 iOS App 遠端存取 Codex 來使用 ChatGPT Voice。

🎯 **實務啟示**

語音模式從單純的「對話工具」轉向「操作工具」，這意味著 LLM 的應用正從資訊檢索走向「Agentic Workflow（代理工作流）」。對於工程師而言，這代表語音將成為驅動自動化流程（如：自動建立 PR、管理工作流）的新介面。
