📌 【Decart 最新發佈】Oasis 3：將「世界模型」API 化，打造物理 AI 的開發生態系

當我們討論世界模型（World Models）時，大多數人想到的是 Sora 或 Runway 產出的精美影片。但 Decart 這次採取了不同的策略：他們不只想產出影片，而是要讓開發者能透過 API，在實時（Real-time）環境中「編程」出一個可互動的物理世界。

🤔 **從影片生成到「可互動」的物理模擬**

目前的影片生成模型大多是「一次性」的產出，但對於自駕車（AV）或機器人開發者來說，真正需要的是能夠根據輸入即時反應、且符合物理邏輯的模擬環境。

Decart 推出的 Oasis 3 正是針對此需求設計。它能生成照片級（Photorealistic）的駕駛環境，且最關鍵的是「可互動性」與「實時性」，讓開發者能在大規模模擬中測試那些在現實中極其罕見且危險的駕駛場景（Edge Cases），而無需實際出車。

🧪 **基於 Lucy 基礎模型的物理 AI 演進**

Oasis 3 並非憑空而來，它是建立在 Decart 先前的實時影片模型 Lucy 之上。Lucy 已經在電商與直播領域累積了超過 10 萬名開發者的使用經驗，而 Oasis 3 則是將這種實時生成能力轉向「物理 AI」（Physical AI）的嘗試。

這意味著 Decart 試圖將其模型從單純的視覺生成，轉化為一種能夠模擬物理世界運作邏輯的底層基礎設施。

💡 **對標 OpenAI：試圖建立世界模型的開發生態系**

Decart 的野心不僅在於提供一個模擬工具，而是想複製 OpenAI 在 LLM 領域的成功路徑：透過 API 開放，讓開發者在模型之上構建應用。

CEO Dean Leitersdorf 指出，Oasis 3 將成為第一個人們能真正地在其之上進行「編程」的可用世界模型。這種從「工具」轉向「平台」的策略，旨在吸引一個龐大的開發者社群，將世界模型變成物理 AI 的標準開發介面。

⚠️ **激烈的競爭環境與實作成本**

儘管 Oasis 3 具有先發的 API 優勢，但世界模型賽道已極其擁擠：
- Google 的 Genie 3 已進入研究預覽階段。
- 李飛飛的 World Labs 推出了商業化方案 Marble。
- Luma 與 Runway 也在將其具備物理感知（Physics-aware）的影片模型轉化為世界模型。

此外，實時生成的成本依然高昂。目前 Oasis 3 的定價為每秒 0.02 美元，這對於大規模壓力測試的成本控制將是一個關鍵考量。

🎯 **實務啟示：物理 AI 的測試將進入「生成式」時代**

對於自駕車工程師與機器人研究者來說，這項研究與產品的啟示在於：
- **邊緣案例（Edge Cases）的量產**：未來不再需要耗費大量人力設計 3D 模擬場景，而是透過世界模型直接生成無數種可能的危險情境。
- **開發流程轉向 API 化**：物理模擬將從「安裝軟體」轉向「調用 API」，開發速度將大幅提升。
- **跨領域遷移**：從駕駛模擬出發，未來這套邏輯極可能擴展到工業機器人或複雜的物理交互場景。
