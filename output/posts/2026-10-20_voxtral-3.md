📌 【Mistral 官方發布】Voxtral 3：能聽、能想、能動手的語音 Agent

TL;DR：Mistral 推出 Voxtral 3 語音模型家族與 Voice Agent SDK，支援 50+ 語言即時語音互動與工具呼叫，且可自架部署。

想像一位病患打電話來，用法文念出轉診信上的內容，AI 客服不只聽懂、翻譯給你，還直接幫你查詢轉診單號、訂好看診時間——這不是示範影片的腳本,而是 Mistral 在 Voxtral 3 發布文中展示的實際對話流程。

🤔 **語音 Agent 的四個難題**

Mistral 指出，一個可靠的語音 agent 必須同時做好四件事：跨語言、跨口音、能處理插話的精準聽取；理解使用者在特定情境下真正想表達的意思；用帶有情感與自然語調的語音回應；以及透過多步驟操作連接的系統完成任務。要讓這四者在即時環境下穩定協同運作，一直是語音應用的技術瓶頸。

🧩 **一條管線整合聽、想、說、動手**

Voxtral 3 是一個新的語音模型家族，加上一套 Voice Agent SDK，把聆聽、推理、工具呼叫與語音生成整合進單一即時串流管線。核心元件包括：

- **Voxtral Small Transcribe 3 / Voxtral Mini Transcribe 3**：語音轉文字模型，支援 50+ 語言，具備語者分離（diarization）、關鍵詞語境偏置（context-biasing）、以及偵測使用者說完話的「結束發言偵測」(end-of-turn detection)。Mini 版本為 4B 參數，定價每分鐘 0.0035 美元。
- **Voxtral Mini TTS 3**：文字轉語音模型，能依對話情境調整情感、語速與語氣重音，支援 35+ 語言與 50+ 方言。
- **Voice Agent SDK**：把聽、推理、工具呼叫、說話整合成即時體驗，agent 可在電話或網頁通話過程中即時查詢資訊、串接企業系統、完成多步驟任務（如前述的轉診預約案例）。
- **Pro Voice**：面向專業場景的語音克隆，只需 30 分鐘音訊，即可跨語言重現特定說話者的個性、情感範圍與說話風格。

部署方式上，Voxtral 3 可透過 Mistral 的 EU 託管 API 使用，也能在自有基礎設施上自架部署,讓企業能自行決定音訊處理位置與資料是否保留，符合資料主權（data sovereignty）的需求。

📊 **多語言辨識與語者分離數據**

根據 Mistral 公開的 FLEURS 多語言基準（涵蓋 45 種語言的交集，Forced 為指定語言、Inferred 為自動偵測語言），Voxtral Small Transcribe 3 的詞錯率（WER）表現優於多款對手：

| 模型 | Forced WER | Inferred WER |
|---|---|---|
| Voxtral Small Transcribe 3 | 4.1% | 4.0% |
| Microsoft AI Transcribe 2 | 4.1% | 4.0% |
| Voxtral Mini Transcribe 3 | 4.6% | 4.5% |
| Gemini 3.5 Transcribe | 6.1% | 4.5% |
| Scribe v2 | 4.9% | 4.9% |
| GPT Transcribe | 6.3% | 5.6% |
| Whisper large-v3 | 16.0% | 14.9% |

在語者分離（diarization）的 cpWER 基準（涵蓋 AMI-IHM、AMI-SDM、Switchboard 等公開資料集）上，Voxtral Small Transcribe 3 以 18.4% 排名最低（越低越好），優於 Pyannote Orchestrator、Microsoft AI Transcribe 2、Scribe v2 與 Gemini 3.5 Transcribe（38.4%）。

在 Earnings 22 基準的關鍵詞召回率（keyphrase recall）測試中，加入領域關鍵詞與說話者名稱作為 context 後，Voxtral Small Transcribe 3 的召回率可提升至約 94.6%，相較未提供 context 時有明顯提升，顯示 context-biasing 機制能有效提升專業術語場景下的辨識準確度，且不需額外微調模型。

🎯 **實務啟示**

對於正在打造客服、服務臺或免手動操作助理的工程師，Voxtral 3 把「聽、理解、工具呼叫、說」整合進同一串流管線，省去了過去自行拼接 ASR、LLM、TTS 三套系統的整合成本；而 EU 託管與自架部署雙選項,也讓需要資料主權合規的企業（如金融、醫療場景）有更明確的落地路徑。context-biasing 與 diarization 的基準表現,對需要處理專業術語或多人對話紀錄的應用（如客服、會議紀錄）尤其值得評估。
