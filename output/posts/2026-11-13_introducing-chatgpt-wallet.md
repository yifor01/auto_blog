📌 OpenAI 推出 ChatGPT Wallet，讓 Agent 學會刷卡下單

TL;DR：OpenAI 推出 ChatGPT Wallet，讓 ChatGPT Work、Codex、dots 裡的 agent 能在使用者核准下完成購買。

當 AI agent 已經能幫你寫程式、查資料、訂會議室，下一步自然會走到「幫你把錢付掉」。問題是，誰敢把信用卡交給一個會自己做決定的程式？

🤔 **Agent 任務卡在「付款」這一關**

許多 agent 要完成的任務，最後一步往往是一筆實際的交易，例如訂閱某個服務或採購一項工具。過去 agent 頂多能「建議」使用者去結帳，卻沒有一個安全、受控的方式真正完成購買這個動作。

🧩 **ChatGPT Wallet：核准制付款 + 既有信用卡保護**

根據 OpenAI 官方部落格，ChatGPT Wallet 是一套讓 ChatGPT Work、Codex 與 dots 裡的 agent 能夠完成購買的機制，核心設計是「使用者核准」加上「沿用既有信用卡保護機制」。也就是說，agent 執行購買動作前需要經過人工確認，且交易仍受原本信用卡的保障機制涵蓋，而非繞過這些保護另建一套規則。

目前公開資訊僅提及這項功能會出現在 ChatGPT Work、Codex、dots 這三個產品介面中，尚未看到更多關於實作細節、適用地區或支援卡組織的說明。

🎯 **實務啟示**

對於在這些產品上打造工作流程或整合 agent 的工程師來說，這代表「付款」正式成為 agent 可以安全執行的動作類型之一。在設計自己的 agent 流程時，可以參考這種「關鍵動作前插入使用者核准、並沿用現有防護機制」的模式，而不是自行設計一套全新的授權邏輯。
