📌 【普林斯頓／螞蟻／史丹佛】AQuA：量化 Agent 如何不騙自己

TL;DR：AQuA 把資料路徑與評分規則鎖在迴圈外，讓量化研究 Agent 的自我改進經得起驗證。

量化研究員看到一條異常漂亮的回測曲線，通常不會馬上慶祝，而是先問：是不是哪裡用了未來資料？測試集有沒有被反覆檢視？收益是否只來自一段特殊行情？這套職業習慣背後藏著一條樸素的經驗：產生一個好結果不難，證明它值得相信才難。當 Agent 開始自己提出假設、執行實驗、再根據結果決定下一步時，這個問題會變得更棘手，因為一次沒被發現的資料洩漏，可能被系統當成成功經驗儲存下來，Agent 從此不是在持續進步，而是沿著一個錯誤結論越走越遠。

🤔 核心問題：讓實驗成為下一次研究的依據，但不能連評分標準一起改

來自普林斯頓大學、螞蟻集團與史丹佛大學的研究團隊在論文《AQuA: Recursively Self-Improving Quantitative Trading Research Agents》中處理的正是這件事。AQuA 所說的 recursive self-improvement 不涉及底層模型權重，變化發生在研究過程本身：實驗開始前，系統先形成可檢驗的假設（因子研究要寫清經濟機制、預測方向與證偽條件；模型研究則把想法落成一次配置修改）；實驗結束後，系統儲存的不只是 IC 或 Sharpe，還包括候選為什麼被提出、在哪些市場狀態下成立、與哪些簡單基線重複、什麼證據推翻了最初判斷。已經多次失敗的機制不會只是換個說法再出現，方向判斷錯誤但仍有預測力的訊號可以校準後保留。這和單純給 Agent 加一個長期記憶模組不同：記憶能否提高研究品質，取決於其中儲存的證據是否可靠，若一次有洩漏的實驗被寫成「有效」，更長的記憶只會讓錯誤傳播得更遠。因此 AQuA 把兩件事拆開：Agent 可以根據過去結果改變研究方向，但不能同時改變產生這些結果的資料和評分方法。

🧩 一次真實的資料洩漏事故，倒推出現在的架構

論文附錄記錄了一次早期失敗。當時 Agent 可以直接寫特徵程式碼，另一個 Agent 負責檢查前視偏差。候選特徵是「盤中成交量參與率」，即從開盤到當前時刻的累計成交量相對於日成交量的比例，按文字描述似乎只依賴已發生的交易，審查 Agent 也因此放行。但程式碼裡的分母其實是當天從開盤到收盤的總成交量，中午計算特徵時，下午還沒發生的成交量就已經進入分母；另一個多時間尺度版本也有類似問題。這個洩漏帶來了遠高於常規價量特徵的 held-out IC，重新劃分評估視窗後效果沒有保留，研究人員才逐項追查到這個全日成交量分母。值得留意的是，作者 Agent 和審查 Agent 都認為這個特徵只用了歷史資訊，語意理解一致，問題藏在程式實際存取的時間戳裡。這次事故讓團隊放棄「再加一道模型審查」的思路，改成現在的做法：系統預先登記可用的因果運算元和模型元件，Agent 只能在這個範圍內組合表示式或提交配置差分，當天最終成交量不在可用欄位中，上述特徵也就沒機會進入實驗。

🧩 兩種隔離：生成過程與選擇過程

AQuA 區分了兩個容易洩漏的入口。第一個來自生成過程：特徵、標籤、正規化或資料轉換一旦能存取預測時點之後的資訊，實驗從一開始就沒意義，AQuA 在自主迴圈啟動前就固定資料切分、特徵、標籤和評價器，Part I 只能組合登記過的時間序列與截面運算元，Part II 只能修改模型結構、損失函式、取樣器和最佳化器等配置。第二個來自選擇過程：搜尋階段只回傳預先確定的驗證集分數給 Agent，用於候選排序、提前停止與 checkpoint 選擇，最終測試視窗要等配置確定後才執行，結果也不會回傳給 Agent 繼續調參。在 Part II 中，2010—2019 年用於訓練，2020 年當隔離帶，2021—2025 年才是最終測試視窗。這套設計把可信度放在研究環境本身，而不是 Agent 對自身推理的解釋，因為後者難以逐次驗證，前者卻可以透過權限、資料血緣與執行記錄稽核。

📊 兩套獨立系統，同一種研究能力

AQuA 由兩套獨立系統組成，各自跑完「提出假設—構建—評估—驗證—選擇」的迴圈，並獨立更新研究記憶。Part I 研究符號化因子，由 AI Manager 排程六個專業 Agent：Data Steward 管資料品質與對齊、Visual Analyst 找相關市場事件、Idea Miner 提出機制、Factor Evaluator 做統計檢驗、Backtest Engineer 檢查交易含義、Research Librarian 儲存證據並更新研究記憶，所有任務交接都經過 Manager。論文展示的一輪研究從一個市場問題出發：未平倉合約快速下降後，若價格反彈卻沒有主動買盤和基差修復配合，這次反彈是否更容易失敗？系統尋找強制去槓桿事件，比較價格、成交量、基差和 taker flow 的後續變化，寫成可證偽的機制，並檢查效果是否只是現有因子的重複表達。這類機制較好的單因子 IC 約 0.026—0.037，20 輪自主研究後，組合驗證集 Spearman IC 上升到約 0.190，提升來自一組經濟機制不同的弱訊號逐步積累，而非某條突然出現的公式。

Part II 研究可訓練模型，預測每隻美股未來 30 分鐘的收益，每輪只提交一個 config diff，明確記錄改的是模型結構、損失函式還是訓練策略。最終模型採用混合時序架構：多尺度一維卷積提取局部價量變化，時序主幹處理更長距離動態，截面模組在同一時刻混合股票間資訊，讀取層輸出逐股票預測分數；元件登錄檔涵蓋 LSTM、Mamba 和 Transformer，論文實驗配置使用 attention。同一評價器下，最強基線 GRU 逐股票 IC 為 +0.0613，AQuA 搜尋出的混合模型達 +0.0843。訊號經行業中性化，構建成美元中性多空組合，計入雙邊換手成本 2 bps 後，樣本外 Sharpe 為 +2.15，加入只用歷史資料的波動率控制後升至 +2.50；在所有參數只能依據下一段測試前資料確定的 walk-forward 評估中，Sharpe 仍約為 +2.0，2021—2025 年間每年 Sharpe 都為正。兩套系統的數字不能直接橫向比較（0.190 是加密資產五分鐘級組合因子的 Spearman IC，0.0843 是美股逐股票時間序列 raw IC），但共同驗證了同一件事：「證據進入記憶、評價保持獨立」的方法可以落到兩種不同的量化研發任務上。

⚠️ 限制

論文自己承認：Part I 和 Part II 分別只在一個市場和一個預測週期上驗證；交易結果來自模擬回測，尚未經過實盤檢驗；最終測試集的隔離依賴執行權限和審計，不是密碼學意義上的強制隔離。團隊也選擇先把篩選過的因子庫凍結，再作為 Part II 資料沙盒的一部分，而不是直接把兩套系統連起來，以避免前一階段的過擬合因子成為後一階段輸入所形成的新洩漏。

🎯 實務啟示

AQuA 的拆分邏輯不只適用於量化：只要 Agent 可以反覆呼叫同一個評價器，自動調參、材料發現、藥物篩選這類自主研究系統就同時面對「生成過程汙染實驗」和「搜尋過程適應指標」兩種風險。把資料路徑和最終指標明確隔離、只讓通過驗證的證據進入記憶，是一種可以遷移的設計思路；工程師在建構長期執行的研究型 Agent 時，與其信任 Agent 每次都做出正確判斷，不如把信任放進系統的權限與審計設計裡。
