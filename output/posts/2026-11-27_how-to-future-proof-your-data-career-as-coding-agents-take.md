📌 當 Coding Agent 接手苦力活，資料科學家的價值去哪了？

TL;DR：Coding agent 吞下了資料清理與調參雜活，資料科學家要轉型成系統指揮官與領域專家才能保值。

過去一年,一件事悄悄發生了：清理 CSV、寫 boilerplate SQL、調超參數,這些曾經定義資深初階資料職缺的苦力活,現在多半交給 AI 代勞。如果你花了兩年磨練 pandas 技巧或背熟 scikit-learn pipeline,現在該停下來問一句：我的價值到底還剩下什麼?

🤔 **Agent 能做什麼,又為什麼靠不住**

KDnuggets 專欄作者 Vinod Chugani 指出,AI coding agent 已經能自動化特徵工程、超參數最佳化這類資料科學任務,是能大幅提升生產力的工具。但問題出在「資料科學式的懷疑」：agent 擅長寫程式碼,卻不擅長質疑。它會急著為初步成果歡呼,卻不會主動標記資料品質的潛在問題。模型會產出一個模型,但它不會去問目標變數是否定義正確、訓練資料是否真的能代表你關心的那群人,甚至不會問「這個業務真的需要一個模型嗎?」。文章直言,在特定領域的資料科學任務上,人類專家目前仍明顯優於自主 AI agent。模型能寫程式碼,但無法擁有決策。

🧩 **三條能讓你保值的路**

文章給出三個具體方向。第一,成為熟練的 agent 指揮官：把 coding agent 當成要管理的同事,而不是單純的工具,學會把問題拆解成 agent 能穩定執行的形式,知道如何驗證輸出、何時該否決建議。理想的 agentic 工作流程是你負責定義問題、與利害關係人對焦需求,再讓多個專職 agent 平行處理資料準備、分析與初步建模,同時記錄進度、標記問題。文章推薦的學習資源包括 DeepLearning.AI 的「AI Agents in LangGraph」課程、Coursera 上 Google 的「Introduction to Responsible AI」,以及 Eric J. Ma 的「How to Do Agentic Data Science」。

第二,加深領域專業。Agent 沒有產業脈絡,它不知道電信業的流失率模型要考慮季節性合約續約,不知道醫療業的詐欺偵測模型必須符合 HIPAA 規範,也不知道行銷團隊三年來優化的指標其實只是另一個真正目標的代理指標。這種脈絡只能靠人累積,文章建議從 O'Reilly 的產業專書、所屬垂直領域的產業通訊與期刊,以及 Coursera 的產業專項證書(如醫療資料科學、金融科技)入手。

第三,培養統計與科學懷疑精神。文章點出 agent 增強工作流中最常見的失敗模式：輸出看起來完全正確——數字合理、視覺化乾淨、模型準確率體面——但整個分析建立在一個沒人抓到的錯誤前提上。這時候需要有人問：這符合我對因果關係的理解嗎?有沒有干擾變數?評估指標是否真的對齊業務結果?這個發現是不是資料假象?文章推薦 YouTube 頻道 StatQuest with Josh Starmer 培養統計直覺,以及 Carl Bergstrom 與 Jevin West 的《Calling Bullshit: The Art of Skepticism in a Data-Driven World》。

💡 **留下來的恰好是最有趣的部分**

文章的核心論點值得玩味：會被自動化掉的,恰好是資料科學中比較枯燥的部分;留下來的——問對問題、判斷模型是否真的該存在、挑出資料假象——反而是這份工作最有知識趣味的地方。這既令人不安(早期建立職涯的技能正快速貶值),也令人釋然(留下來的恰恰最難被取代)。

🎯 **實務啟示**

如果你還在靠「熟練寫 pipeline」定位自己,現在是轉向的時機：練習寫精確、可驗證的 agent prompt,設計多步驟流程並建立稽核習慣;同時認真投資一個垂直領域,讓自己擁有 agent 永遠學不到的產業直覺;最後,把統計懷疑精神當成日常反射動作,而不是選修課。
