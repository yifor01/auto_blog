📌 不刷卡也能試 Agentic Coding：5 款免費 AI coding agent

TL;DR：盤點 5 款可免費體驗頂尖模型的 AI coding agent，不用先付費買 API。

想試用最新的 agentic coding 模型，卻卡在「先綁信用卡」這一步？其實現在不少強大的開源與專有模型，已經可以透過免費額度直接在編碼代理裡試用，根本不需要先掏錢。

🤔 問題：好工具常常被付費門檻擋在前面

AI coding agent 能檢視 repository、編輯檔案、執行終端機指令、除錯、跑測試，完整走過一輪開發任務，這是目前這波 AI 浪潮最實用的部分之一。但問題是，許多 coding agent 仍要求先訂閱付費方案或準備好 API key 才能真正上手試用。以下整理的 5 款工具，重點就是提供不用預先支付 API 費用也能實際體驗 agentic coding 的管道。

🧩 五款工具與各自的免費入口

| Coding Agent | 免費模型來源 | 適合場景 |
|---|---|---|
| OpenCode | OpenCode Zen 免費模型 | 綜合體驗最佳 |
| Gemini CLI | Gemini 免費額度 | 免費額度最寬鬆 |
| Kilo Code | Kilo Gateway 免費模型 | 免費模型選擇最多 |
| Cline | Cline Provider 免費模型 | IDE 使用者 |
| Crush | Charm Hyper 免費方案 | 終端機體驗最佳 |

OpenCode 是一款終端機內的開源 coding agent，可探索 repository、編輯檔案、執行多步驟開發任務。其中 OpenCode Zen 是作者常用的功能：新模型發布時，通常會有免費選項可以直接在工作流程裡測試，不必另外設定 provider 或付費購買額度，免費目錄裡包含 Muse Spark、Ling、NVIDIA Nemotron 等變體模型，以及一些實驗性或促銷版本，內容會隨時間變動。

Gemini CLI 是 Google 開源的終端機 coding agent，能理解 repository、修改檔案、執行 shell 指令、使用工具並完成多步驟任務。只要用符合資格的 Google 帳號登入即可開始使用 Google 最新的 Gemini 模型，不需要購買 API 額度或設定其他 provider，但免費額度仍有速率與用量限制，適合測試、學習與小型任務，不建議用於大型正式專案的持續重度開發。

Kilo Code 原本是 VS Code 上的 coding agent，現在已擴展成涵蓋 VS Code、JetBrains、CLI 與雲端服務的生態系，支援數百種模型。它的免費託管模型選擇特別多，在模型選單裡搜尋「free」即可查看目前可用的選項（內容會隨 provider 與促銷活動變動，部分模型可能有上游速率限制）。更方便的是 Auto Free（kilo-auto/free）功能，不需自己挑選模型，系統會自動把請求導向目前最好的免費模型，完全不需要額度。

Cline 是另一款作者喜歡的 coding agent，偏好直接在 IDE 內工作的使用者會特別適合，它能檢視程式碼庫、建立與修改檔案、執行終端機指令、檢查錯誤、跑測試，並持續迭代直到完成任務，同時讓使用者在允許重要變更前，清楚看到代理打算做什麼。透過 Cline Provider，登入後在模型選擇器裡尋找標示 FREE 的選項即可使用免費模型，這些選項會隨時間變動，通常附帶用量限制。

Crush 由 Charm 團隊打造（Bubble Tea、Gum 等工具的開發者），主打終端機體驗，同時具備檔案編輯、終端機指令、LSP 整合、MCP 伺服器與多步驟任務支援等完整代理功能。其免費入口是 Charm 自家的模型 provider「Charm Hyper」，提供免費方案，安裝 Crush、選擇 Hyper 模型並登入即可開始使用，免費方案目前每月提供 100 個 Hypercredits，足以用來測試 Crush 與其部分程式碼模型。

💡 作者怎麼選

作者建議若是第一次嘗試，可以先從 OpenCode 開始，因為它在代理能力、模型彈性與免費存取之間的平衡最好；之後再依個人工作習慣選擇：想用 Google 的 Gemini 模型就選 Gemini CLI，想要大量免費託管模型選擇就選 Kilo Code，偏好在 IDE 內工作就選 Cline，喜歡純終端機體驗就選 Crush。

⚠️ 免費額度終究有限制

這些免費管道的額度可能隨時變動，促銷模型也可能下架，對於大型正式專案的持續重度開發來說，免費額度通常不夠用，比較適合測試、學習與中小型任務。

🎯 實務啟示

對工程師而言，這類免費入口的實際價值在於能快速比較不同模型在真實 agentic coding 任務裡的表現，再決定要不要為特定模型或工具付費擴充額度，省下一輪一輪申請 API key、填信用卡資訊的摸索成本。
