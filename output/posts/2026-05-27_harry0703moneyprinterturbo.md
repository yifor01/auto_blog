📌 AI短影片生成工具  

你以為製作短影片要花費數小時？這個開源專案讓你只需輸入一句關鍵字，就能自動產出完整影片。  

🤔 **短影片製作通常需要專業工具與大量時間**  
隨著短視訊平台的爆發，個人與小團隊常面臨腳本寫作、素材搜尋、字幕製作與配音等多個環節，導致製作成本高、門檻深。  

🧪 **MoneyPrinterTurbo 提供一鍵式管線，從關鍵字自動產出文案、素材、字幕與配音**  
該專案採用 MVC 架構，使用者只需提供影片主題或關鍵字，系統會依序呼叫 LLM 生成腳本、從免版權素材庫抓取畫面、合成字幕、加入背景音樂，最後輸出高清短片。支援 9:16 竖屏與 16:9 橫屏兩種尺寸，並可批量生成多個版本供選擇。  

💡 **該工具支援多種視訊尺寸、批量生成及可自訂的字幕與音效**  
使用者可調整視訊長度、字體、顏色、位置與描邊，亦可自行指定背景音樂或使用隨機選曲。字幕與音效皆可即時試聽，方便快速微調。  

💡 **透過整合多家大模型與 TTS 服務，降低對單一供應商的依賴**  
MoneyPrinterTurbo 能接入 OpenAI、Moonshot、Azure、gpt4free、one-api、通義千問、Google Gemini、Ollama、DeepSeek、MiniMax、文心一言、Pollinations、ModelScope 等多種 LLM，並支援多種語音合成引擎。對中國用戶，官方建議使用 DeepSeek 或 Moonshot，因為它們可直接訪問且註冊即送額度。  

⚠️ **目前仍需依賴外部 API 且對 GPU 的需求視使用情況而定**  
雖然核心處理可在 CPU 上完成，但若啟用本地語音識別（faster‑whisper）、大規模批量生成或更重的素材處理，GPU 會顯著提升速度。官方提供 Windows 一鍵啟動包、uv 同步部署、Docker 與 Google Colab 三種安裝方式，降低環境配置門檻。  

🎯 **適合快速原型、內容行銷或教學影片的快速製作**  
對於需要快速測試創意、產出宣傳片或製作教學補充材料的開發者與內容創作者，MoneyPrinterTurbo 提供一個可即時上手的管線。透過 API 或 Web 介面，可將影片生成流程納入自動化工作流。
