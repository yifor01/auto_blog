📌 DeepSeek一週雙喜：新旗艦模型上線，同時傳出740億美元上市估值

TL;DR：DeepSeek同週發新模型又傳IPO消息，中國AI晶片廠Enflame掛牌大漲，Anthropic則指控中國實驗室蒸餾自家模型，三件事共同勾勒出中美AI競速的當下局勢。

同一週裡，DeepSeek一手放出新模型，一手傳出籌備上市；大洋另一端，Anthropic則指控三家中國實驗室「蒸餾」自家模型訓練資料。這些事看似分屬不同新聞版面，實則都是同一條主線的不同切面：中國AI產業正加速衝刺，而美國的防線也在同時收緊。

🤔 這一週，中國AI圈同時發生了三件大事

- **DeepSeek 出貨新旗艦**：DeepSeek-V4.1-Flash 是一款 552B 參數的 MoE（Mixture-of-Experts）模型，每個 token 僅啟動 8–16B 參數，在 Terminal-Bench 2.1 的 coding 與 agentic 任務上，據稱贏過 OpenAI 的 GPT-5.6 Sol 與 Moonshot 的 Kimi K3。
- **同週傳出上市籌備**：DeepSeek 據報已聘請中信證券等四家承銷商，準備在上海科創板（STAR Market）掛牌，pre-IPO 輪估值約人民幣 5000 億元（約 740 億美元）。
- **Enflame 掛牌暴漲**：這家騰訊投資、被視為 Nvidia 挑戰者的 AI 晶片廠在科創板 IPO 募資 61.2 億元人民幣，股價一度飆升 234%，收盤仍上漲 188%，市值逼近 255 億美元。Enflame 是中國「AI 晶片四小龍」（另三家為 Moore Threads、Biren、MetaX）中最後一家上市的公司。

📊 蒸餾指控與晶片熱潮的另一面

Anthropic 同週表示，已中斷多起活動，指控三家中國實驗室透過 Claude 路由數百萬筆使用者查詢，藉此蒐集訓練資料進行蒸餾。美國官員迅速將此定調為「產業級」的 AI 技術竊取，時間點恰好落在川普與習近平預定會面前兩週；北京方面則全盤否認，並警告將採取反制措施。

同一份週報也提到，中國 AI 晶片廠正因高頻寬記憶體（HBM）短缺而調漲價格，這對正搭上晶片 IPO 熱潮的所有廠商都是隱憂；而繼 Unitree 上市首日股價劇烈波動後，監管單位據報也在收緊後續人形機器人 IPO 的審批。

🧩 生態圈裡，其他值得留意的出貨

除了旗艦模型之爭，這一週也有幾項對工程師更「可上手」的動態：阿里巴巴 Qwen 為個人開發者升級 Token Plan，新增 12 項 Agent Harness 工具；騰訊混元開源了語音生成與編輯基礎模型 AuK；螞蟻集團開源視覺語言模型 Ling-3.0-flash-VL，提供 BF16、FP8 版本，並規劃推出 FP4/INT4。位元組跳動、阿里巴巴、騰訊也不約而同把資源轉向「AI 數位員工」辦公室 Agent，騰訊 WorkBuddy 更開放 Agent 平臺給第三方開發者串接。

💡 這些事同時發生，不是巧合

模型能力、資本市場、地緣政治這三條線正在同一時間點交會：DeepSeek 用更小的啟動參數量做出有競爭力的 coding 模型，證明中國實驗室在效率最佳化上持續逼近前緣；晶片股的狂熱反映的是「去 Nvidia 化」的資本敘事；而 Anthropic 的蒸餾指控，則暴露出美國陣營對於「護城河」正被稀釋的焦慮。三者疊加，指向的是同一個問題：模型能力的擴散速度，可能比任何一方的政策應對都快。

🎯 對工程師的實務啟示

如果你在評估 coding agent 或推論成本，V4.1-Flash 的 MoE 啟動參數設計值得關注，這代表在特定任務上，「小啟動量、大參數池」的架構路線正逐漸證明可行。同時，Qwen Agent Harness、AuK、Ling-3.0-flash-VL 這類開源釋出，也意味著非美系模型生態的可用工具正在快速補齊，值得納入技術選型的雷達。
