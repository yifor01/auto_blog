📌 【OpenAI 官方發布】內部前沿模型挑戰數學開放問題，證明公開上 GitHub

TL;DR：OpenAI 分享內部前沿模型在數學開放問題上的新結果與 Lean 證明。

讓一個 AI 模型去碰數學界還沒解決的開放問題，通常只會換來一堆錯誤或空話；但 OpenAI 這次選擇把結果連同形式化證明一起公開，接受外界檢驗。

🤔 **發生了什麼事**

OpenAI 發布文章表示，他們內部一個前沿（frontier）模型在數學的開放問題上產出了新的結果，並且將對應的 Lean 證明形式化（proof formalization）與研究細節發布在 GitHub 上。

🧩 **為什麼選擇 Lean 形式化證明**

材料中特別強調的是「Lean 證明形式化」這個做法。Lean 是一套可以讓證明被電腦逐步檢驗的形式化證明語言，把模型產出的數學證明寫成 Lean 可驗證的形式，等於讓結果的正確性不必只靠人工審稿背書，而是可以被工具直接檢查每一個推導步驟。這也讓外部研究者能直接在 GitHub 上檢視、重現或挑戰這些結果。

⚠️ **公開摘要透露的細節有限**
