📌 OpenAI 發布 GPT‑5.6 系列：Sol、Terra、Luna，Codex 變身 ChatGPT 超級應用

TL;DR：OpenAI 推出三款新尺寸的 GPT‑5.6，採用「ultra」多 Agent 並行推理，可在更少時間與成本下超越同代模型，同時 Codex 桌面版升級為 ChatGPT 超級應用。

🧩 **全新尺寸對應星體概念**  
OpenAI 為 GPT‑5.6 取名 Sol、Terra、Luna，分別象徵太陽、地球、月球的相對規模。這種命名方式與 Claude 系列的文學式尺寸形成對比，讓使用者一眼即能感受模型容量差異。

🧩 **「ultra」與「max」兩大效能設定**  
- **max**：比先前的 xhigh 設定給予模型更長的思考時間，允許 GPT‑5.6 在推理過程中探索更多備選方案、執行檢查並自行調整策略。  
- **ultra**：在 max 基礎上，預設同時協調四個 Agent 並行工作，犧牲較高的 token 使用量，以換取更強的結果與更快的完成速度，特別適合高需求任務。

🧩 **效能與成本的雙贏**  
根據多項基準測試（包括文中未列出的測試），GPT‑5.6 在效能與成本上均優於 Fable 與 Opus 系列。具體表現如下：  
- **Terra**：略高於 Fable 5 的表現。  
- **Luna**：超過 Opus 4.8。  
- 兩者皆在約三分之一的時間內完成，同時產出 token 數減半，估算成本僅為原先的四分之一。  

📊 **新基準創下領先紀錄**  
GPT‑5.6 在 Terminal‑Bench 2.1（測試複雜命令列工作流程）與 DeepSWE（長期工程實作於真實程式碼庫）上均創下最新的 state‑of‑the‑art 成績，顯示其在長程推理與實務程式開發上的強大能力。

💡 **Beyond Benchmarks：實務應用提升**  
除了量化基準，OpenAI 也提到在以下領域的顯著改進，雖未提供具體資料，但值得關注：  
- 電腦使用與自動化操作  
- 檔案與簡報生成  
- 科學研究輔助  

⚠️ **超級應用的最後一步**  
OpenAI 於 7/08‑7/09 期間同時更新了 ChatGPT Work 與 Codex 桌面版應用。Codex 現已整合至 ChatGPT 超級應用（superapp）平臺，成為開發者日常工作的重要工具。唯一未明確說明的部分是「Agentic Browser」的未來走向，仍是觀察焦點。

🎯 **實務啟示**  
- 若你的工作流程需要同時處理多個子任務（如資料前處理、模型推理、結果驗證），可考慮使用 GPT‑5.6 的 ultra 設定，以四 Agent 並行加速完成。  
- 成本敏感的應用可選擇 Terra 或 Luna，利用其較低 token 消耗與成本，仍能取得比前代模型更好的效能。
