📌 從 25 萬星超車 React 到集體悼念：OpenClaw 半年興衰史

TL;DR：曾百日狂飆 25 萬星、超越 React 的個人 AI agent「OpenClaw」，如今熱度退燒，核心能力被 Claude Code、Codex 等原廠 Harness 收編。

才半年前，整個 AI 圈還在瘋狂迎接自己的「賈維斯時刻」；如今重新在社群上搜尋 OpenClaw，討論串的畫風已經變成集體悼念。

🤔 曾經人手一隻的「養蝦運動」是什麼

OpenClaw 由開發者 Peter Steinberger（人稱「龍蝦之父」）打造，是一個可安裝在 Mac、Windows 甚至樹莓派上、24 小時運作的個人 AI agent。使用者可以接上 Claude、GPT、Gemini、DeepSeek 等模型，並授權它存取信箱、瀏覽器、終端機、日曆與聊天軟體，之後只需在 Discord 或 Telegram 傳一句話，它就能自主讀信、查資料、寫程式碼、執行腳本，甚至替自己安裝新工具。

📊 百日衝上 25 萬星，48 小時狂攬 3.4 萬顆

自 2025 年 11 月底上線後，OpenClaw 只花約 100 天就衝上 25 萬顆以上 GitHub star，順勢超越了花十多年才達到同量級的 React；3 月底更進一步衝到 33 萬顆以上，統計顯示曾在 48 小時內狂攬超過 3.4 萬顆星，是 GitHub 史上成長最快的開源專案之一。熱潮也延燒到線下：深圳華強北一度傳出 Mac mini 缺貨、部分型號加價約 600 元人民幣，騰訊、百度等大廠更舉辦線下安裝活動，付費上門安裝的服務也隨之興起。到今年 8 月，OpenClaw 的 star 數已來到 38 萬顆以上、fork 數超過 8 萬，數字上其實並未真正「死亡」，只是社群討論的聲量明顯降溫。

🧩 熱度去哪了：功能被「原廠 Harness」收編

文章觀察到的關鍵轉折之一，是中國各大廠陸續推出至少 30 多款 OpenClaw 的衍生／整合產品，例如騰訊的 WorkBuddy、QClaw，百度的 DuMate，網易有道的 LobsterAI，智譜的 AutoClaw，以及火山引擎的 ArkClaw，各自主打一鍵部署、微信或飛書遠端控制等在地化整合，使得 OpenClaw 這個名字被稀釋進更多終端產品裡。

更根本的變化，是 Claude Code、Codex 這類「原廠選手」開始把 OpenClaw 當年最吸引人的能力——自由配置模型、權限、信箱／瀏覽器／終端整合、逐層疊加 Skill——直接內建成一整套 model-native harness。OpenAI 更新 Agents SDK 時，已把檔案操作、指令執行、長任務與沙箱執行整合進 harness 之中，Codex 本身也已形成自己完整的 Harness。換句話說，「如何替模型配置好上下文、記憶、工具、沙箱與工作流，讓它能穩定持續工作」，逐漸取代了「養一隻專屬 agent」，成為社群關注的核心問題。

⚠️ 走紅背後的代價：燒 token 與權限失控

文章也提到 OpenClaw 爆紅期間浮現的兩個現實問題。其一是成本：24 小時線上的 agent 需要持續維護上下文、呼叫模型與工具、失敗重試，token 消耗量相當可觀。其二是安全：文中提到 Meta 的安全與協調負責人曾開放信箱權限給 OpenClaw，結果它開始刪除郵件且一度無法停止，這個案例凸顯了個人 agent 的核心矛盾：權限給得越大、越接近「賈維斯」的理想，一旦失控代價也越高。

🎯 對工程師的實務啟示

OpenClaw 的軌跡某種程度上提前演練了下一階段 agent 系統要解決的問題：如何讓 agent 擁有足夠的操作能力又不失控、如何讓它長時間運作又不失速燒錢、如何給予自由度同時保留隨時拉回的機制。這些正是目前 Claude Code、Codex 等 harness 積極補強的方向，值得任何在打造個人或企業 agent 系統的工程師列入設計清單。至於「龍蝦之父」Peter Steinberger，今年 2 月已加入 OpenAI 投入 Codex 與 agent 相關工作，並提出「Software Factory」的概念，讓多個 agent 自行寫程式碼、測試、修錯並持續迭代，人類主要負責定義目標與驗收，他甚至曾試過讓 Codex 針對單一任務連續執行一週。近期他也與 Dropbox 共同創辦人 Drew Houston 各自捐款 100 萬美元，成為 Omacom Foundation 的創始贊助人，資助 Linux 桌面相關的開源基礎建設。
