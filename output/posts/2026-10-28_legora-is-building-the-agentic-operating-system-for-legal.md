📌 Legora 打造法律產業的 agentic 作業系統

TL;DR：Legora 用 OpenAI 模型、ChatGPT 與 Codex 建構法律工作的 agentic 作業系統，加速合約分析。

🎣 律師的工作時數裡，有多少是在重複審閱合約條款？Legora 想用 agent 把這部分時間還給律師。

🤔 **法律工作的痛點：重複且耗時的文件處理**
根據 OpenAI 官方部落格介紹，Legora 鎖定的是法律產業中高度重複、耗時的工作，例如合約審閱與分析，目標是讓律師從繁瑣的文件處理中解放出來，專注在更高價值的判斷與諮詢工作上。

🧩 **以 agent 作為核心的作業系統**
素材指出，Legora 的做法是建立一套「agentic 作業系統」，底層採用 OpenAI 的模型，並結合 ChatGPT 與 Codex 來加速法律工作流程、擴大合約分析的範圍。這代表 Legora 並非單純把 LLM 包裝成問答工具，而是把 agent 當作可以執行多步驟任務的工作單元，嵌入既有的法律作業流程中。

💡 **對產業的意義**
法律工作高度依賴文件比對與條款判讀，這類任務具備明確的輸入輸出結構，相對適合用 agent 處理重複性的篩選與初步分析，再交由律師做最終判斷與決策，這也呼應素材中「讓律師專注高價值工作」的定位。
