📌 Anthropic 把 MCP 捐給基金會：Agent 生態的「介面」時代來了

TL;DR：Anthropic 將 Model Context Protocol 捐贈給 Linux Foundation 旗下新設的 Agentic AI Foundation，讓 AI agent 的溝通標準脫離單一廠商掌控。

過去一年 AI 圈最重要的新聞,不是來自某個新模型的發表會,而是來自一個標準制定組織。當 Agent 之間、Agent 與工具之間如何「對話」開始被寫進中立基金會的治理章程裡,這意味著 AI 應用的地基正在從「各家自訂協議」轉向「共同介面」。

🤔 **從單一廠商協議到公益信託基金**

根據報導,Anthropic 在 2025 年 12 月將其開發的 Model Context Protocol（MCP）捐贈給新成立的 Agentic AI Foundation,這是 Linux Foundation 底下的一個 directed fund（指定用途基金）,由 Anthropic、Block 等機構共同發起。MCP 原本是 Anthropic 用來讓 LLM 應用能以標準化方式存取外部工具、資料來源與服務的協議,如今治理權轉移到中立的基金會架構下。

💡 **為什麼「捐出協議」本身就是大事**

一項協議只要還掛在單一公司名下,其他廠商在導入時難免有所保留:規格會不會突然改版?會不會被拿來綁定商業利益?把 MCP 移交給 Linux Foundation 這樣的中立治理實體,等於是向整個產業釋出訊號——這不是 Anthropic 的產品功能,而是大家可以共同治理、共同貢獻的基礎設施。這與 HTTP、TCP/IP 等網際網路基礎協議走過的路徑類似:先由某個組織提出雛形,再交由中立機構維護,才能真正成為跨廠商、跨生態系都願意採用的共同語言。

🎯 **實務啟示**

如果你正在打造 agent 應用或工具整合層,MCP 的治理轉移是一個訊號:值得評估將自家工具、資料源以 MCP 相容介面暴露出來,而不是自訂一套私有協議。當協議由中立基金會維護,長期維護成本與相容性風險都會降低,也更容易搭上未來其他廠商陸續支援 MCP 的生態紅利。
