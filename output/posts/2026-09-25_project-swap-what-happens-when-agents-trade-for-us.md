📌 【Anthropic 實驗】201 位員工的 AI 代理人上場喬換書

TL;DR：Anthropic 讓 201 名員工的 AI 代理人互相議價換書，發現模型能力比 prompt 指令更決定議價成敗。

如果你的 AI agent 代表你去跟別人的 agent 討價還價，它真的懂你想要什麼嗎？這個問題聽起來抽象，Anthropic 卻找了 201 名員工，搭了一座真實的交易市場來測試答案。

🤔 **為什麼好交易常常沒發生**

生活中充滿了本可以讓雙方都更好的交易，卻因為找到對的交易對象、談出條件太花力氣而從未成真：病人因為一家診所報價太貴就放棄治療，卻不知道另一家收費更低，或原本那家其實願意在被要求時降價；理想的工作機會與合適的僱主可能就在附近，卻因為雙方都沒時間持續搜尋而錯過彼此。日常生活裡也有排班互換、共乘拼車、代接送孩子這類容易被忽略的小型交易。如果有一個 agent 全天候替你去找潛在交易對象並談條件，這些交易會不會就此成真？這牽涉到一連串還沒有答案的問題：agent 真的理解你嗎？當許多 agent 齊聚一堂互相交涉時，誰來訂定「誰能入場、交易破局怎麼辦、市場活動對參與者是否可見」這些規則？

這是 Anthropic 第二次做類似實驗。第一次「Project Deal」讓 agent 在一個為期一週的分類廣告市集裡替員工買賣真實物品，但因為商品五花八門（乒乓球、雪板等）且議價方式自由開放，很難有客觀標準去衡量交易結果好壞。這次他們改用更容易量化評分的設計。

🧩 **一場以書換書的實驗**

201 名 Anthropic 員工分布在舊金山、紐約、倫敦、西雅圖、華盛頓特區與都柏林六個辦公室，各地人數從 3 人（都柏林）到 115 人（舊金山）不等。每位參與者帶來一本自己想送出的書。接著，每人與 Claude 進行一段簡短、半結構化的對話，聊聊自己的閱讀喜好與這個夏天想讀什麼類型的書。Claude（此步驟使用 Fable 5 模型）根據這段對話，為每位參與者建構出對其所在書池中每一本書的排序預測。

為了驗證這個預測的準確度，Anthropic 另外收集了「真實答案」：每位參與者親自從自己書池中挑出 10 本書排序，這份排序 agent 從未看過。之後，agent 帶著各自估計出的偏好上場，在數位「交易大廳」裡向其他 agent 推銷、討價、談成交易，直到時間結束，參與者最終拿回自己 agent 談來的書。

📊 **五分鐘對話，猜中六成一的偏好順序**

結果顯示，僅憑一段五分鐘的對話，agent 對書籍的排序預測與參與者本人排序相比，兩兩配對比較的一致率達到 61%——對這麼短的對話來說，這個結果被形容為「意外地好」。

Anthropic 接著把每個交易大廳重跑了數十次，分別更換所用的模型與給 agent 的指令。結果發現：**agent 所使用的模型，比給它的指令內容，更能左右議價結果**；使用更強模型的市場，整體交易效率也更高。此外，大多數拿到書的人都表示喜歡這本書，平均每位參與者表示，願意把自己每年書籍預算的三分之一左右交給 Claude 代為支配。

💡 **市場卡關的原因，不在議價本身**

Anthropic 指出，這個市場表現不如預期，主要原因是 agent 對參與者掌握的資訊不足，而不是議價過程本身出了問題——也就是說，瓶頸出現在「理解使用者偏好」這一端，而非「談判技巧」這一端。文章也區分了兩種市場設計：集中式市場需要一個「清算所」角色統籌所有人的需求並直接算出最佳配對，但參與者必須把資訊交給並信任這個中心單位，實務上常常沒有這樣的單位存在，或人們不願意全盤告知；去中心化市場則靠每個人（或其 agent）自行找對象、自行談判。由於 AI agent 的「注意力」遠比人類仲介（如房仲、獵頭）便宜，理論上有機會讓過去只有付得起仲介費的人才能享有的「全天候代理人」服務，普及到更多人身上。

⚠️ **樣本規模與未解問題**

都柏林辦公室僅 3 人參與，因此被排除在多數分析之外；素材也提到「大多數人」對拿到的書感到滿意，暗示並非所有人都如此，但具體比例與原因未在摘錄中說明。此外，這個以書換書的簡化情境是否能推廣到更複雜、真實的市場（如求職或醫療報價），目前仍是未知數。

🎯 **實務啟示**

對於設計 AI 議價系統或多 agent 市場的工程師來說，這個實驗的重點提示是：真正的瓶頸往往出在「如何讓 agent 準確理解使用者偏好」，而不是「如何調校議價指令」；同時，選用更強的底層模型，可能比雕琢 prompt 更能改善整體協商結果。
