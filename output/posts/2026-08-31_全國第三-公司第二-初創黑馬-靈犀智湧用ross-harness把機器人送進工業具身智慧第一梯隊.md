📌 【靈犀智湧】沒有頂尖硬體，靠 Harness 拿下全國第三

TL;DR：靈犀智湧用自研 ROSS Harness，把 Demo 級機器人送進工業賽事全國前三名。

一家成立僅三個月的公司，帶著一臺用 Demo 級本體組裝出來的機器人，站上了世界人形機器人運動會的工業場景賽場，對手全是硬體積累深厚的頭部品牌。結果它不但晉級決賽，還以 160 分拿下全國第三，成為工業場景賽中除行業頭部企業外唯一獲獎的機器人公司。

🤔 硬體不佔優，怎麼贏

第二屆世界人形機器人運動會的 51 個賽項分兩條評價體系：競技賽測運動極限與協同能力，場景賽則直接對標真實崗位標準。工業場景裝配上料崗屬於後者，評判核心指向工業級交付最看重的長時程穩定性、毫米級精度，以及擾動下的自主恢復能力。文章指出，頭部公司再漂亮的 Demo，到了真實工業場景常卡在成功率不穩、吞吐率不夠、運維太貴、遷移太難這四件事上，底層原因指向單一模型路線的方法論侷限：模型輸出終究是機率性的，單次成功率有天花板，而工業場景是開放世界，若系統缺乏自進化能力，經驗就無法沉澱為可複用資產。靈犀智湧沒有把賭注押在本體，而是押在一套自研的 ROSS Harness Agent 上。

🧩 以控制論命名的執行閉環

ROSS Harness 由公司聯合創辦人、CTO 段逸凡博士領銜自研，這套系統以控制論奠基人 W. Ross Ashby 命名，定位是圍繞具身模型建構的工業級執行體系，在模型與機器人之間建立持續執行的閉環，把模型機率性的動作能力轉化為穩定、可控、可複用的生產能力。文章列出五項核心能力：

- 模型抽象：把 VLA、World Action Model 等模型統一到標準介面，新模型只需局部適配，上層的任務規劃、Skill 編排、安全策略和機器人控制模組可以繼續複用，降低模型快速迭代帶來的系統重構成本。
- 技能抽象：把模型、工具和工程策略封裝成帶有適用條件、安全約束、結果判斷和失敗處理的 Skill，讓散落在程式碼、參數與工程師經驗中的 know-how，變成可呼叫、可遷移的數位能力資產。
- Agentic AI：Agent 負責目標理解、任務拆解、Skill 編排與異常恢復，在模型的靈活性與工業執行的確定性之間畫出邊界，避免大模型在每一步執行中自由發揮。
- 分層安全監控：從毫秒級硬體安全、秒級軌跡監督到任務級狀態判斷，持續判斷機器人是否正常執行，異常時觸發中斷、重試、回退、替代 Skill 或重新規劃。
- 資料飛輪：任務上下文、失敗案例、人工接管與恢復路徑都會結構化沉澱，用來更新 Skill、最佳化任務編排、完善恢復策略與長期記憶，並進一步反饋給模型。

文章把這套思路總結成一個公式：Embodied Agent = Embodied Model + Embodied Harness + Hardware。模型越強，Harness 能呼叫的能力邊界就越大；Harness 累積的真實工業經驗，又能反過來幫助模型更理解工業任務。靈犀智湧並沒有因此放棄模型，公司自研的 CONWAY 工業原生模型持續在力覺增強、快速推理、動作對齊與安全控制等方向演進，目的不是和通用基座模型比拚參數規模，而是持續掌握具身模型的能力邊界，為 Harness 的設計提供模型側支撐。

🎯 實務啟示

靈犀智湧接下來要把賽場驗證過的 Harness 能力，透過標準化硬體平臺推向更多工業場景。文章拿 Coding Agent 類比：同樣的基座模型放進不同的 Coding Agent Harness（例如 Codex、Claude Code），任務表現可能天差地別，因為模型決定它會不會，Harness 決定它能不能真正把事情做成。對工業具身智慧而言，「機器人出廠時多強」之外，「機器人進廠後能不能越用越強」，或許才是走向大規模落地的關鍵一步。
