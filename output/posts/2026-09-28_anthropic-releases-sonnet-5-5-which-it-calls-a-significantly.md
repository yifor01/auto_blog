📌 【Anthropic】Sonnet 5.5 上線：比前代快三成，Agentic Coding 上反超 Opus

TL;DR：Anthropic 發布 Sonnet 5.5，主打更快、更省，agentic coding 表現甚至優於旗艦 Opus 5.5。

在 AI 模型大戰持續延燒之際，Anthropic 這次選擇的戰場不是「更聰明」，而是「更快、更便宜」——距離三個月前發布的 Sonnet 5，這款中階模型的下一代版本已經上線。

🤔 **從「省成本」到「拚速度」**

Sonnet 5 當初的賣點是能以比競爭對手更低的成本運行 Agent。Sonnet 5.5 這次接棒的賣點換成了速度：Anthropic 宣稱 Sonnet 5.5 比前代快 30%，且 token 消耗速度明顯變慢。在 Anthropic 的模型階層中，Sonnet 定位在 Opus 之下，但因為靈活敏捷,在特定情境下反而更實用。

📊 **Agentic Coding 上贏過自家旗艦 Opus 5.5**

Anthropic 公布的 benchmark 顯示，Sonnet 5.5 在 agentic coding 任務上的表現優於 Opus 5.5，文章推測原因可能是 Sonnet 5.5 能在不超出成本限制的情況下衍生多個 sub-agent。此外，Anthropic 表示 Sonnet 5.5 具備「與 Opus 5 相當」的 cyber 能力，這也讓 Sonnet 5.5 成為第一款需要套用與 Fable、Opus 同等級 cyber 安全防護的 Sonnet 模型。Anthropic 同時透露，新版 Haiku（其最小型模型）也將在未來幾週內發布，但目前尚未給出確切時間。

💡 **軍備競賽仍在加速**

這次發布也發生在整個產業密集發新模型的節奏中：就在上週，OpenAI 才發布了包括中階模型 Sol 與平價模型 Luna 在內的多個強化版本；Meta 也宣布了將為其智慧眼鏡新功能提供動力的新模型。對照之下，Anthropic 這次選擇用「速度與成本」而非單純的能力提升作為 Sonnet 5.5 的核心賣點，某種程度反映出中階模型的競爭已經從「誰更強」轉向「誰在生產環境裡更划算」。

🎯 **實務啟示**

如果你的應用場景本來就在用 Sonnet 系列做 agentic 開發或日常辦公文件生成，Sonnet 5.5 帶來的速度提升與 token 消耗下降，值得評估是否能直接無痛升級；而如果你的 workload 涉及需要 spawn 多個 sub-agent 的複雜 coding 任務，Anthropic 自家 benchmark 顯示 Sonnet 5.5 在這類任務上甚至優於 Opus 5.5，代表評估模型時「哪個型號」不再單純看跑分高低，也要看它能否在成本限制內衍生足夠的 Agent 並行工作。
