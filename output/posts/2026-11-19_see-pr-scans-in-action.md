📌 PR Scans 實機演練：掃描結果這樣看

TL;DR：示範影片展示如何在 pull request 流程中直接檢視掃描結果。

Code review 最讓人頭痛的,往往不是沒有掃描工具,而是掃描結果散落在別的系統裡,review 的人還要切換畫面才能看懂。OpenAI 這段影片要示範的,正是怎麼在 PR 裡面直接把結果看完。

🤔 掃描結果,就在 PR 畫面裡

根據官方頁面說明，這是一段 PR scans 的操作走查影片，核心內容是呈現「presenter 如何在 pull request 工作流程中檢視掃描結果」。素材並未說明這些掃描具體檢查的是什麼類型的問題。

🧩 流程聚焦在「審查」這一步

從描述來看，影片的重點放在審查者實際查看掃描結果的動作上，而不是掃描本身如何執行。換句話說,這是一段針對「怎麼讀懂結果」而非「怎麼設定掃描」的示範。

💡 把結果留在開發者原本的工作場域

把掃描結果直接呈現在 PR 介面裡，而不是另開一個獨立的儀表板，是 CI/CD 工具整合上常見的設計方向，目的是讓審查者不用離開既有工作流程就能做判斷。

🎯 實務啟示

評估導入自動化掃描工具時，「結果要不要出現在 PR 裡」本身就是一個影響採用率的設計決策。這段影片提供的是審查端的體驗示範，想掌握完整操作細節,建議直接觀看原始影片。
