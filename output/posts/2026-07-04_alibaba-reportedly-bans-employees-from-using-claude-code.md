📌 阿里巴巴停用 Claude Code，內部導向自研工具 Qoder

TL;DR：阿里巴巴將於 7 月 10 日起停用 Claude Code，並要求員工改用內部工具 Qoder。

當開發者開始依賴高效的 AI 程式碼工具時，企業的資安考量與地緣政治限制往往成為不可逾越的紅線。阿里巴巴近日傳出將全面禁止員工使用 Anthropic 的程式碼工具 Claude Code。

🤔 **禁令背後的合規與風險考量**

根據報導，阿里巴巴已將 Claude Code 歸類為「高風險軟體」，並指示員工轉而使用公司自研的 Qoder 工具。此舉反映出企業在面對外部 AI 工具時，對資安與合規性的高度警覺。

🧩 **Anthropic 的封鎖機制與「辨識實驗」**

這場禁令的背景是 Anthropic 長期以來對中國公司及其關聯實體的限制。為了堵住中國使用者存取 Claude 的漏洞，Anthropic 據傳採取了以下行動：

- 部署特定版本的 Claude Code：部分使用者在 Reddit 發現，該版本能秘密辨識中國使用者。
- 官方解釋：Anthropic 的 Thariq Shihipar 在 X 上表示，這是在 3 月啟動的一項實驗，目的在於防止未經授權的轉售商濫用帳號，並防止「模型蒸餾」（Distillation，即利用一個模型的輸出結果來訓練另一個模型）。
- 目前進度：Shihipar 指出，團隊隨後已採取更強而有力的緩解措施，並計劃移除該實驗功能。

🎯 **實務啟示**

對於企業開發者而言，此事件提醒了兩點關鍵：首先，使用第三方 AI 工具時必須確認公司合規政策，避免因使用「高風險軟體」導致資安風險；其次，模型供應商（如 Anthropic）正強化對存取許可權的監控，透過技術手段防止模型被蒸餾或非法轉售，開發者應留意工具的可用性與合規風險。
