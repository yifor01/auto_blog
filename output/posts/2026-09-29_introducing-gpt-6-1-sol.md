📌 OpenAI 發布 GPT-6.1 Sol：效能逼近 Astra，價格砍到五分之一

TL;DR：GPT-6.1 Sol 效能近 Astra，API 價格僅為五分之一。

當頂尖模型的效能持續攀升，價格往往同步上漲，但 OpenAI 這次選擇反其道而行。

🤔 定位：不是頂規，卻夠用

根據 OpenAI 官方部落格，GPT-6.1 Sol 被定位為「near-Astra intelligence」，意即在 coding、computer use（電腦操作）與一般專業工作場景中，效能已相當接近旗艦模型 GPT-6 Astra。

💡 一次砍到五分之一的 API 價格

OpenAI 表示，GPT-6.1 Sol 的 API 輸入與輸出 token 價格，僅為 Astra 標準價格的五分之一。這代表工程師若原本受限於預算而無法大量呼叫旗艦模型，如今能以更低成本取得相近的效能水準。

🎯 實務啟示

對正在評估模型選型的團隊而言，GPT-6.1 Sol 提供了介於「頂規效能」與「成本可控」之間的新選項，尤其適合需要大量呼叫 API 的 coding agent、computer use 自動化或批次處理任務。若專案對精確度的要求不到 Astra 頂規水準，值得將 Sol 納入 A/B 測試比較。
