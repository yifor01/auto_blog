📌 Healthcare AI GYM for Medical Agents：多輪臨床推理不會越練越笨了？

近年醫療 Agent 快速崛起，但多輪問答與推理訓練卻常出現一個反直覺現象：模型在強化學習過程中逐漸退化為囉唆的單輪互動，把原本該分步驟、循證的臨床推理壓縮成一次過的長篇大論，穩定度與表現同步下滑。

🤔 **多輪臨床推理的強化學習正在退化**

在醫療場景中，循序推理與上下文保持不僅影響效率，更牽涉安全與可解釋性。然而，當前以強化學習訓練多輪醫療 Agent 時，常出現策略退化：系統為求回報穩定，傾向用冗長但單次的回覆取代結構化的多輪互動，導致推理深度與交互質量雙雙流失。

🧪 **自我蒸餘框架提升訓練穩定與性能**

研究團隊針對多輪臨床推理訓練設計強化學習環境，並引入一種新型自我蒸餘（self-distillation）機制。透過讓模型在多輪交互中持續對齊自身較穩定的早期推導軌跡，抑制策略在訓練中滑向囉嗦單輪行為，在持續優化回報的同時維持推理結構。

☁️ **退化現象減少，推理穩定度與表現雙提升**

- 未加自我蒸餘時，多輪交互品質隨訓練進行下滑，回覆冗長且結構稀釋  
- 引入自我蒸餘後，策略穩定性顯著改善，多輪推理品質與效能同步提升  
- 結果顯示，該框架有助醫療 Agent 在長序列臨床推理中保持循環與可驗證的思考模式

💡 **穩定訓練機制決定 Agent 是否「越用越聰明」**

這項研究的核心洞察在於：強化學習本身不保證更複雜的策略，反而可能放大噪聲與退化路徑。自我蒸餘的作用不是增加訊息量，而是作為策略的正則與記憶錨點，幫助模型在探索中保留已驗證的推理結構，這正是多輪醫療 Agent 能夠「穩定進化」的關鍵。

⚠️ **實驗設定局限，長期部署效果仍需驗證**

- 論文未公開具體實驗規模與數據集細節  
- 醫療 Agent 的真實部署涉及合規、監督與長期漂移問題，這類穩定訓練框架在實際環境中的持續有效性仍有待檢驗  
- 自我蒸餘的計算成本與最優觸發機制未在本研究中詳述

🎯 **開源訓練環境可復現，醫療 Agent 穩定化值得優先嘗試**

- 將自我蒸餘納入多輪 RL 訓練流程，有助減少策略退化風險  
- 結構化推理應作為回報設計的一部分，而非僅優化終端結果
