📌 **頁面代理：用自然語言操控網頁**  
你想告訴網頁「幫我填這張表」，卻不用寫一行程式碼或安裝瀏覽器外掛？

🤔 **AI 輔助操作常需重架後端或額外權限**  
許多 SaaS 想要內建 AI Copilot 時，得撰寫後端 API、導入頭less 浏覽器或申請特殊權限，開發門檻與維護成本都不低。這也使得想透過語音或自然語言提升可存取性的團隊卻步。

🧪 **一行 JavaScript 即可嵌入的頁面內代理**  
Page Agent 以純前端腳本形式提供：  
- 透過 `<script src="...">` 一行引入，無需瀏覽器擴充、Python 環境或 headless browser。  
- 全程在網頁內進行文字化 DOM 操作，不依賴螢幕截圖或多模態 LLM，也不需要額外權限。  
- 支援「自帶 LLM」：開發者可接入自家的語言模型，亦可使用官方提供的免費 Demo LLM（僅供技術評估）。  
- 提供可選的 Chrome 擴充功能，實現跨分頁多頁面任務；同時附帶 MCP Server（Beta），讓外部客戶端透過協議控制瀏覽器。

💡 **核心功能：零程式碼的 AI Copilot、智慧表單填寫、無障礙存取**  
- **SaaS AI Copilot**：只要幾行程式碼，即可在產品內嵌入能理解自然語言的操作助手，無需重寫後端。  
- **Smart Form Filling**：將原本需要二十餘次點擊的工作流程縮減為單句指令，特別適用於 ERP、CRM、後台管理系統。  
- **Accessibility**：透過語音或螢幕閱讀器，任何網頁都能經由自然語言操作，降低使用門檻。  
- **Multi‑page Agent**：透過瀏覽器擴充功能，讓同一個代理跨越不同分頁執行任務。

🔍 **見解：把「思考」留給使用者，讓 AI 只負責「執行」**  
Page Agent 的設計避免了依賴圖像理解的多模態模型，而是直接操作 DOM，這意味著它的決策基礎是純文字指令與頁面結構。這樣的做法既降低了對計算資源的需求，也讓開發者能更清楚地追蹤代理的行為——因為所有互動都可透過程式碼追蹤，而不是隱藏在圖像特徵裡。

⚠️ **限制：僅供技術評估的 Demo LLM 及擴充功能仍處於 Beta**  
- 官方提供的免費 Demo LLM API 僅適合技術評估，實際產品上建議自行接入穩定的語言模型服務。  
- Chrome 擴充功能與 MCP Server 目前標示為 Beta，跨分頁控制與外部協議的穩定性仍需進一步驗證。  
- 由於純文字 DOM 操作，對於某些高度動態或 Canvas 需繪製的介面，可能需要額外的適配工作。

🎯 **實務建議：先以最小成本驗證自然語言互動的價值**  
- 在內部管理後台或客服系統中試用一行腳本，量測「填表」或「查詢」指令所減少的點擊次數與使用者滿意度。  
- 若需跨頁流程（例如從產品頁跳到訂單頁再進行付款），可先啟用 Chrome 擴充功能進行小規模測試。  
- 對於無障礙需求，直接利用語音輸入與頁面代理結合，即可達成「零門檻」操作而不必重建整個 UI。
