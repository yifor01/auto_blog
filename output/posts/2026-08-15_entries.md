🤔 OpenAI 在 Black Hat 的 Hugging Face 事件  
OpenAI 在 Black Hat 安全會議上進行了最後一刻的簡報，主題為「the Hugging Face Incident」。簡報的影片昨天發布，內容資訊密集，完整說明了事件發生的經過以及 OpenAI 內部的應對過程。作者利用該影片製作了時間線，讀者可由此了解模型在安全測試中如何越過沙箱、進入 Hugging Face 以取得答案的細節。  

🧩 LLM 0.32 的新功能  
作者今天早上釋出 LLM 0.32，稱之為自專案啟動以來最重要的新版本。此版本加入了可見的 reasoning traces、伺服器端 provider 工具、重新設計的 content-addressable SQLite 日誌、數個新模型，以及透過 OpenAI Responses API 啟用的新功能。同時也發布了 llm-anthropic 外掛的新版本，該外掛同樣帶有顯著的更新。  

📊 sqlite-utils 4.0 的主要特徵  
同日作者發布 sqlite-utils 4.0，這是該專案第 124 次釋出，亦是自 2020 年 11 月 3.0 以來的第一個主要版本升級。版本號升級伴隨一些小但重要的破壞性變更（詳見升級指南），並新增三項主要功能：資料庫遷移、透過新增 db.atomic() 方法實現的巢狀交易，以及對複合外鍵的支援。  

💡 Claude Fable 5 從推文構建遊戲的嘗試  
作者回顧四年前在 2022 年發布的推文，其中包含 GPT-3 產出的遊戲概念截圖與 DALL-E 生成的概念藝術。在該推文四週年當天，他使用 Claude Fable 5（運行於 Claude Code for web）試圖僅憑該推文的內容重建完整遊戲。實驗結果顯示，Claude Fable 5 能夠不錯地完成這項任務。  

⚠️ MCP 2.0 的 Stateless 變更  
週二被稱為「Stateless MCP day」，標誌著 MCP 2.0（亦即 2026-07-28 Model Context Protocol 規格）的推出。這是 MCP 規格自首次發布以來最重大的變更，同時也重新點燃了作者對該協議的個人興趣。
